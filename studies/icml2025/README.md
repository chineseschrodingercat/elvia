# ICML 2025 completed reports

This collection publishes exactly 400 completed reports in maintainer-selected
batches B001–B004 (100 papers each). It adds first-edition immutable snapshots
without repeating scientific review. Independent scientific decisions remain
pending; publication is preliminary AI-assisted analysis.

`import-manifest.json` records paper identity, batch, title, original source/report
hashes and public-copy bindings. `records/` is authoritative. `source/` and
`evidence/` retain public source notes, existing findings, coverage and complete
report transcriptions. Raw archive files remain unchanged outside the repository.
Operational identifiers and host paths are omitted from public copies.

`case-notes.json`, `reader-catalog.json` and `research-fields.json` provide
snapshot-bound presentation, citations/credit and principal-field discovery.
PDFs remain in a separate explicit publication library outside Git.

Original ELVIA analyses are CC BY 4.0; source articles retain their own terms.
See [the publication decision](../../docs/decisions/0008-icml-publication-fields.md)
and [Issue #18](https://github.com/chineseschrodingercat/elvia/issues/18).
