Abstract: The inspected fixed-minibatch-gradient construction and nonlinear primal/dual equivalence are valid. A Major issue is demonstrated in the released optimized decoding route: CUDA graph replay freezes the within-minibatch position used by the update coefficient and rotary encoding. A reachable layer-state example changes the output even after normalization. This compromises the semantic correctness of the released decoding-latency reproduction route, without establishing an error in JAX perplexities, prefill latency or historical timing values. Local indexing and nonparametric-formulation issues are Minor; historical run correspondence remains Needs Evidence.

# Positive checks on the core mathematical construction

Within a minibatch, training gradients are evaluated at the same initial weights. If \(a_s\) are training features, \(g_s\) backpropagated errors and \(q_t\) the current query feature, then \[W_t=W_0-\eta\sum_{s\le t}g_sa_s^\top
 \quad\Longrightarrow\quad
 W_tq_t=W_0q_t-\eta\sum_{s\le t}g_s(a_s^\top q_t).\] This identity holds even when \(q_t\) is produced by earlier layers with their updated weights. Applying it successively proves the multilayer construction in Appendix A, pp. 13–14. There is no need to keep the updated query feature equal to its training-time feature. Layer normalization can be handled by its vector–Jacobian product.

For an independent nonlinear diagnostic, take \(f(q)=w_2(w_1q)^2\), initial \((w_1,w_2)=(0.7,-0.4)\), half-squared loss, \(\eta=0.1\), keys \((0.5,1.2)\), labels \((0.3,-0.2)\), and queries \((1.1,-0.7)\). Direct prefix updates give \[(-0.23136126745712346,\;-0.09056472939607373).\] The separately evaluated dual formula agrees within \(8.4\times10^{-17}\). This numerical check accompanies the identity, rather than replacing its proof. The inspected JAX linear/MLP paths use common minibatch initial weights, causal masks and final-prefix carry states consistently.

Theorem 1, p. 5, is also correct for the unnormalized dot-product attention defined by its proof: \(W_0=0\), squared loss, batch gradients and \(\eta=1/2\) give \[W_t=\sum_{s\le t}(Vx_s)(Kx_s)^\top,\qquad
 z_t=\sum_{s\le t}(Vx_s)(Kx_s)^\top Qx_t.\] This is a scoped No Issue Found; it is not an identity for every normalized kernel-attention variant.

# Problems

Problem 1 (Major: captured decoding freezes the update position).  The inference-kernel release explicitly presents its script as reproducing the paper’s prefill/decode throughput, associated with Section 3.3 and Figure 8, p. 8. Its shipped benchmark enables CUDA graphs. The captured decoding route does not implement the position-dependent TTT state transition at each replay.

All code anchors in this problem are inside . The dependency is explicit:

- `benchmark_prefill_decode.py:115--124` calls generation with `cg=True`.

- `ttt/generation.py:281--282` sets the Python integer `seqlen_offset` to `max_seqlen-decoding_seqlen` during capture.

- `ttt/modeling_ttt.py:389--393` uses that integer modulo 16 to select ; lines 1396–1401 create position IDs from the same integer, overriding any supplied IDs. Lines 401–403 use the resulting phase in rotary encoding.

- Graph dispatch keys include batch size, decoding length, prefill status and final-token status, but no within-batch position (`generation.py:245--263`). Replay copies only input IDs (`315--318`); the allocated position tensor is unused.

CUDA graph replay does not rerun the Python argument/index selection performed at capture [cuda]. Therefore incrementing the outer Python offset does not update those captured operations. The current last-token Boolean selects the correct commit/reset branch, but cannot repair the coefficient or rotary phase inside that graph.

For the shipped prompt length 1 and generation length 512, capture occurs at offset \(513-1=512\), phase 0. The initialized coefficient is therefore always 1, instead of the intended sequence \(1,1/2,\ldots,1/16\). The error directly reaches \[W_{\rm new}=W_{\rm base}-\alpha_tG_W,\qquad
 b_{\rm new}=b_{\rm base}-\alpha_tG_b\] in the decoding kernel; it is not an unused index.

A reachable normalized-output witness. A second supported setting, prompt length 16 and generation length 16, captures at offset 31, phase 15. The first subsequent decode evaluation has actual offset 16, phase 0. Let head dimension be 64, normalization epsilon \(e=10^{-6}\), normalization scale/bias \((1,0)\), and effective gated learning rate \(L=1/128\). Set \[z=(1,-1,0,0)^{\times16},\qquad
 r=(0,0,1,-1)^{\times16}.\] At the start of a minibatch take cached bias \(b=z\), zero gradient buffers, current query/key zero and value \(r\). This bias is reachable from zero bias: a preceding 16-token prefill with zero queries/keys, first value \(2.048z\) and remaining values zero produces it under the same frozen-gradient update and final coefficient \(1/16\).

Since \(z\) and \(r\) are centered and orthogonal, the normalization-loss gradient is exactly \[g=\frac{e}{(1/2+e)^2}z-\frac{1}{\sqrt{1/2+e}}r.\] The correct and captured biases are \(z-Lg\) and \(z-Lg/16\). Applying the actual output normalization gives the first four coordinates \[\begin{aligned}
 {\rm correct}:&\quad
 (1.414125840,-1.414125840,0.015624016,-0.015624016),\\
 {\rm captured}:&\quad
 (1.414211811,-1.414211811,0.000976560,-0.000976560).\end{aligned}\] The maximum difference is \(0.0146474553\). This independent real-arithmetic calculation uses the inspected layer formulas, not author-code execution. Queries/keys are zero, so rotary effects cannot explain away or cancel the coefficient witness. It does not claim a measured fp16/GPU error or a particular language-model score.

Impact, counterevidence and repair scope. The released decoding benchmark times a different state transition from the specified model, a direct failure of its core inference-reproduction role. That supports Major without requiring measured speed loss. It does not establish that the published historical timing used this commit. Ordinary `cg=False` evaluation recomputes the phase. Normal prefill bypasses replay, so the prefill-only timing route is not invalidated. JAX training/perplexity results are separate.

The README openly limits the release to random-token fp16 A100 benchmarking and excludes real serving. Those disclosures limit deployment claims but do not establish correctness of the captured recurrence. The asserted numerical agreement in the README was not independently reproduced and is not bound to a capture-aware validation trace. A repair must supply dynamic phase-dependent inputs or correctly distinguish all phase-dependent graphs, then verify state/output agreement. No such implementation repair or GPU rerun was performed.

Problem 2 (Minor: the minibatch-anchor formula is off by one).  Section 2.4, p. 4, defines \(t'=t-\operatorname{mod}(t,b)\) as the previous minibatch endpoint. For one-based tokens, at \(t=b\) this gives \(t'=t\), rather than zero. The intended anchor is \(b\lfloor(t-1)/b\rfloor\).

With \(b=2\), \(W_0=0\), \(\ell(W)=(W-1)^2\) and \(\eta=0.1\), the intended frozen-anchor updates give \(W_1=0.2\), \(W_2=0.4\). The literal formula combined with equation (5) gives \(W_2=0.2-0.2(W_2-1)=1/3\). The prose, illustration, appendix and inspected source all support the intended previous-minibatch anchor. This is a localized specification error, not evidence that the implemented dual update is wrong. The corrected indexing is algebraically verified.

Problem 3 (Minor: the nonparametric formalization needs consistent arguments and density assumptions).  Theorem 2, p. 6, uses \(\kappa(x,x')\propto\exp((Kx)^\top Qx')\) with the current query as its first argument, reversing the fixed \(Q/K\) roles used earlier. Appendix B’s density-estimation interpretation also requires a normalizable kernel and specified domain/base measure.

For a fixed-parameter witness let \[x_1=e_2,\quad x_2=e_1,\quad
 Q=\begin{pmatrix}1&0\\0&0\end{pmatrix},\quad
 K=\begin{pmatrix}0&1\\0&0\end{pmatrix},\quad V=(1,0).\] At \(t=2\), the preceding attention convention gives scores \((1,0)\) and output \(1/(1+e)=0.2689414214\). The printed kernel gives scores \((0,0)\) and output \(1/2\). The example also survives the literal query projection in equation (4), since \(Qx_2=x_2\).

Using a projected query \(q=Qx_t\) with score \(\exp(q^\top Kx_s)\) restores the intended weighted-average identity. Query/raw-input arguments must be stated consistently. Thus the family-level inclusion of self-attention remains valid; the issue does not refute the proposed parametric TTT layers. Separately, scalar \(Q=K=1\) and center 1 give \(\kappa(x,1)\propto e^x\), nonintegrable over \(\mathbb R\). This is not a Euclidean density kernel without additional conditions. Finite positive weights still define the normalized regression algebra. Asymmetry alone is not the objection.

# Remaining correspondence questions and conclusion

Both the JAX and tutorial releases include a learned prefix normalizer: \[W_t=W_{\rm base}-\alpha_t\sum_{s\le t}\beta_sG_s,\qquad
 \alpha_t=\max(0,1/t+a_t).\] Here \(\beta_s\) contains the token-dependent sigmoid rate and dimension scaling. This output-position factor rescales previous gradients: with \(G_1\ne0,G_2=0,a_t=0\), the second displacement is half the first. It is distinct from the per-gradient \(\eta(x_s)\) description in Section 2.7. The kernel source labels normalization intentional; it is not intrinsically invalid. Its precise connection to the paper’s update and historical ablations remains a method-disclosure question, recorded as Needs Evidence.

The reported \(0.30\) to \(0.27\) seconds per training iteration is arithmetically a 10% reduction. The latency, perplexity and scaling experiments were not rerun. Validation-loader use, BOS masking and dropped incomplete batches in the release do not by themselves establish a historical test-metric error. General conclusions about all modern RNNs also exceed the specific evaluated architectures, data and budgets.
