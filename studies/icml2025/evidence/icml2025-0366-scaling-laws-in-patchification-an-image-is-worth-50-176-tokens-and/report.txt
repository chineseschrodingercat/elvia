An inherited source-manifest count of 25 arose from embedded form-feed characters in figure text, not extra PDF pages; the frozen source was preserved and physical-page extraction was used. # Patchification and information loss

Problem 1 (Needs Evidence: information loss in the trained patch embeddings).  Sections 1, 4.2 and 4.3 repeatedly interpret smaller-patch gains as recovery of visual information irreversibly compressed by patchification. For the base models used in central experiments, patchification need not lose any input information.

A patch has \(3p^2\) scalar coordinates and its embedding is \(z=Wx+b\in\mathbb R^D\). If \(D\geq3p^2\) and \(W\) has full column rank, a left inverse recovers \(x\). For \(p=16,D=768\), the base-model projection is square. With \(W=I\), patch flattening and rearrangement are exactly invertible. At \(224\times224\), \(196\cdot768=224\cdot224\cdot3=150{,}528\): fewer spatial positions do not imply fewer scalar coordinates. For \(p\leq8\) the same \(D\) is already an expansion. An independently constructed integer image was patchified at \(p=16\) and reconstructed exactly with zero error. The inspected code’s patch layer is a strided convolution followed by flattening, with identity normalization, so this counterexample lies within the described layer class.

The introduction qualifies its claim as patchification “often” incurring irreversible loss; it does not state that every patch projection destroys information. The invertible construction therefore does not refute that empirical claim or establish that the trained embeddings are lossless. It rejects only a deduction of necessary information destruction from fewer spatial tokens. Accordingly, this item is Needs Evidence, not a demonstrated error in the actual learned representations.

This does not prove that the trained matrices are full rank, numerically well conditioned, or sufficient for the downstream task. Tiny and small models at large patches can have genuine dimensional bottlenecks. Finite-precision effects and learned rank collapse are also possible. A justified clarification is to distinguish spatial granularity and computational access to coordinates from irreversible input loss. A rank/singular-value study or reconstruction experiment on the actual learned embeddings is needed before assigning the observed gains primarily to lost information.

Needs Evidence: causal interpretation of Table 5. The token-interpolation control shows that simply interpolating coarse tokens gives much smaller gains than reducing patch size. It is useful evidence against that particular sequence-extension method. It does not equalize local token geometry, receptive fields, the learned projection, positional parameterization, or the ease with which mixers access fine structure. Even an invertible patch embedding and a pixel embedding can differ in all these properties while containing identical information. Thus the control does not identify information recovery as the principal cause. An invertible space-to-depth baseline, fixed/invertible projection controls and matched parameter/compute experiments would separate these explanations more directly.

# Empirical scaling and its limits

Tables 1 and 4 show increasing ImageNet accuracy at each tested patch size. The headline sequence length is correct: \(224^2=50{,}176\) image tokens (plus the separate class token in the inspected model), and the displayed Adventurer-Base accuracy improves from \(82.6\%\) to \(84.6\%\). The longest ViT experiment is restricted to 4,096 image tokens; the 50,176-token result uses Adventurer, so it should not be attributed to a full-resolution pixel ViT experiment.

Figures 1–4 were actually inspected. Figure 1 contains approximately straight trends over a handful of log-scaled points, but the paper supplies neither a fitted exponent with uncertainty nor an out-of-range predictive test. The claim on page 6 that smaller patches guarantee performance gains is stronger than a finite empirical sweep. Successive base-model gains at \(224^2\) are \(1.3,0.4,0.2,0.1\) percentage points. Without seed-level variation, the last increment cannot be assigned statistical certainty. “Observed scaling trend” is supported; a universal guarantee or theoretical scaling law is not established.

The compute cost is disclosed rather than hidden: Table 6 reports \(27.45\) versus \(115.08\) normalized A100 GPU-hours per ImageNet epoch for Adventurer at \(p=2\) and \(p=1\), a factor of about \(4.19\) for the final \(0.1\)-point gain. The runs are not equal-training-compute comparisons. The appendix correctly describes the GPU-hour numbers as multi-node measurements/estimates normalized by GPU count, with memory excluding model and optimizer storage. This supports feasibility, not compute optimality. The multi-stage recipe reuses \(128^2\) pretraining before 120 additional epochs at \(224^2\); those are not 120 total epochs from scratch.

For ADE20k, Figure 2’s decoder advantage declines from 1.7 to 0.1 mIoU across the tested patch sizes. A linear classification head remains; “decoder-free” means omitting UperNet. Detection and instance segmentation still use Cascade Mask R-CNN. Table 3’s finest tested base model uses \(p=4\), while the tiny model reaches \(p=2\); the text’s shared \(p=2\) hardware-limit description should be narrowed accordingly. These observations support reduced decoder benefit on the tested segmentation setting, not elimination of all task heads across dense tasks.

# Static source checks

The acquired release is Patch_Scaling commit `fb8cce8c015d4d9ac04b73d2521751e10e0f5af3` (25 February 2025). Static reading covered `models_mamba.py` lines 32–55, 160–216 and 254–332, `main.py` lines 298–351, and the README’s evaluation/training instructions. The code has an explicit non-overlapping patch convolution, appends the class token at the end, and uses learned absolute positional embeddings. Only this release is characterized; no author program, checkpoint or training job was executed.

Needs Evidence: parameter-count convention. In the inspected base model, the learned positional tensor has \((L+1)D\) parameters. At \(224^2\), changing \(p=16\) to \(p=1\) increases it from \(151{,}296\) to \(38{,}535{,}936\) parameters. The convolution decreases from \(590{,}592\) to \(3{,}072\). With other blocks fixed, their net change is therefore \(37{,}797{,}120\) parameters, much more than the roughly 1M difference between the paper’s 99M baseline and 100M pixel-model descriptions. The paper may count only core blocks, use a different positional scheme, or use a different checkpoint; none is established here. Specify the parameter inventory and paper-matched code. This is also a possible additional capacity change that should be accounted for in causal comparisons; no impact on historical accuracies is inferred.

Problem 2 (Minor, release-scoped: position transfer assumes the wrong class-token end).  The model appends its class token after image tokens (models_mamba.py 260–262), whereas the resolution-transfer routine preserves the first positional entry as the extra token and interpolates the remaining entries (main.py 332–345).

For a symbolic stored sequence \([p_0,p_1,p_2,p_3,c]\), the correct image grid is \([p_0,p_1,p_2,p_3]\) and the retained class position is \(c\). The routine instead retains \(p_0\) and interpolates \([p_1,p_2,p_3,c]\), then concatenates the preserved entry first. Changing grid size thus mixes the old class position into the image grid and does not preserve it as the new last class position. At unchanged grid size the identity interpolation can conceal the issue. Preserve the last entry and interpolate the preceding image entries for this model convention. The multi-resolution recipe makes this path relevant, but its historical invocation and accuracy consequences remain unknown.

# Scope and limitations

The complete scientific main text (physical pages 1–9) and Appendix A (12–13) were read. References on pages 9–11 were not exhaustively verified; separate downstream-task code, interpolation-ablation implementation, raw losses, model checkpoints, repetitions and other paper versions were not available for full verification. Source figures were read visually because their embedded text encoding is malformed. The independent calculations cover invertibility, token counts, parameter differences, cost ratio and the symbolic positional-transfer mismatch. A focused check narrowed the information-loss finding after checking the original claim. Scientific adjudication remains pending and human reviews are empty.
