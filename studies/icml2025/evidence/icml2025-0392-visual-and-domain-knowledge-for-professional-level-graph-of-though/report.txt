Abstract: The published benchmark, prompts and ablations were checked alongside two supplied public code snapshots. A supported Minor release-code issue makes the outcome evaluator’s balanced accuracy conditional on available predictions, while its ordinary accuracy counts missing predictions as errors. A finite calculation demonstrates the discrepancy. Its effect on the published results remains unestablished. A prompt-version difference also requires provenance evidence. Scientific adjudication remains pending.

# Substantive finding

Problem 1 (Outcome balanced accuracy omits missing predictions from its denominators).  In the reorganized release, , lines 47–83, a missing case or missing `model_answer` key enters the `KeyError` handler at lines 57–59, increments `fail`, and continues. Class counts `gt_0` and `gt_1` are incremented only afterwards at lines 70–73. Line 81 includes `fail` in ordinary accuracy; line 83 excludes it from both class denominators. The original repository’s evaluation loop is byte-identical after the loop marker. This differs from full-cohort evaluation under ([eq:ba] (#eq:ba)) whenever predictions are missing.

## Complete finite check

Consider four eligible cases, with true labels \((0,0,1,1)\) and predictions \((0,\bot,1,\bot)\), where \(\bot\) means the corresponding JSON answer key is missing. Both classes occur and both retain at least one valid answer, so the example avoids division by zero and malformed strings. The code’s class counts are \((1,1)\) and correct counts \((1,1)\); hence it prints \[B_{\rm available}=\tfrac12(1/1+1/1)=1.\] On the four-case cohort, treating an absent answer as no correct answer gives \[B_{\rm full}=\tfrac12(1/2+1/2)=\tfrac12.\] The same script’s ordinary accuracy is \(2/(2+2)=1/2\). The independent check recomputes these counts without importing or running either author script. If every answer in one true class is missing, the balanced-accuracy line instead divides by zero. More generally its estimator is \[\frac12\sum_{c=0}^1\frac{T_c}{N_c-M_c},\] with \(M_c\) the missing-answer count, rather than ([eq:ba] (#eq:ba)).

## Counterevidence, impact and repair

If \(M_0=M_1=0\), this issue has no effect. One could deliberately report selective accuracy among answered cases, but then that population, coverage by class, and abstention policy must be stated. The release prints only a global failure count, and the paper describes the class average without a conditional-population qualifier. The discrepancy is a supported local evaluation defect (Minor). Missing raw predictions prevent determining whether the paper’s 71.73% or any comparison changed; this is not evidence of fabricated results or a demonstrated failure of the core benchmark.

A precise full-cohort repair is to count \(N_c\) from all eligible ground-truth cases before answer lookup, use those fixed denominators, and give no correct-answer credit to absent or invalid predictions. Coverage and invalid-response counts should be reported separately. The independent four-case check verifies this repair’s arithmetic, not the complete evaluation pipeline or the published score.

# Unresolved source correspondence

Appendix C.4, pp. 20–21, supplies the clinical four-level score definition, with score 3 defined by cerebral hemisphere devastation. The released outcome inference file contains that clinical text but actually selects `MRI_injury_score_math_knowledge` at lines 228–231. Its lines 159–168 introduce 75% regional thresholds, including assigning score 3 when BGT, ALIC or PLIC injury exceeds 75%. This is not the same prompt as the appendix. For instance, a hypothetical isolated severe BGT injury need not constitute hemisphere devastation, so the two textual rules are not logically equivalent.

This is a verified version difference, while its relevance to historical experiments is Needs Evidence. It is not independently graded as a medical error. Saved request payloads, response files and a contemporaneous commit would establish which prompt produced Table 2 and the ablations. Those files were not in the supplied source-only packet. Current path/filename differences likewise cannot identify the historical execution. No external rerun was attempted.

# Conclusion and limits

The observed performance gains and several ablation arithmetic checks are internally consistent. Full-text reading and selected static tracing do not reproduce the clinical labels, case selection, model calls or confidence intervals. The ZADC/ROI preprocessing scripts and upstream atlas studies were not audited in full. Claims about generalization to independent institutions or causal contribution of each prompt component need evidence beyond the reported small retrospective cohort.
