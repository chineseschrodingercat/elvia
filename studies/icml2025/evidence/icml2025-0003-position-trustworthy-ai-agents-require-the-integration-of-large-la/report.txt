# 2. Problem 1: unsupported verification of the palindrome listing

Location: Appendix A.4.2, p.19, Listing 2 and its surrounding verification claim. The postcondition equates the returned Boolean with the predicate that every first-half array element equals its mirror. Let N be the nonnegative array length. The listing initializes left = 0 and right = N-1; on each iteration it compares arr[left] and arr[right], returns false on mismatch, otherwise increments left and decrements right. It returns true on loop exit.

## 2.1 The result invariant has no establishing assignment

The declared output res is not assigned before the invariant res == true. Under Dafny 3.11 automatic initialization, the verifier treats an uninitialized auto-initializable value as arbitrary; the historical function method syntax makes these semantics relevant [2,3]. Take a non-null array [1,2,1] and res = false: the precondition holds, but the entry invariant fails. Strict definite-assignment checking would instead reject an unassigned read. Neither reading establishes res == true. The exact author tool version and flags were not supplied.

## 2.2 The displayed invariant does not connect the two pointers

An invariant-based loop proof must justify the early return for every state satisfying its invariant and guard [2]. The missing relationship is left + right = N-1. The following countermodel checks every displayed condition, without assuming reachability:

Condition at loop head | Countermodel evaluation

State | arr = [1,2,1]; N = 3; left = 0; right = 1; res = true

Non-null array; bounds | True; 0 <= 0 <= 1+1 <= 3

Result invariant | res == true holds

Processed prefix | 0 <= i < left has no indices; universal statement is true

Processed suffix | Only j = 2 satisfies right < j < N; arr[2] = arr[0] = 1

Guard and branch condition | left < right is 0 < 1; arr[0] != arr[1] is 1 != 2

Required versus returned result | IsPalindrome is true, since arr[0] = arr[2]; branch returns false

Thus the early-return verification condition is false for the displayed annotations. This state is unreachable from the actual initialization: the actual updates preserve left + right = N-1, which this state violates. It is a countermodel to the proposed proof obligations, not a runtime counterexample to the algorithm. The supported consequence is loss of the worked example’s claimed formal verification. Section 5 and the conclusion use the examples to substantiate the integrated trustworthy-action approach, and p.19 specifically claims executable fidelity through formal verification. The false verification condition therefore damages core supporting technical evidence and supports Major. It does not establish an incorrect initialized execution, a failure of formal methods, or a refutation of the general integration position.

## 2.3 Local repair, with an analytic proof

Code:
// Insert before the loop:
res := true;
// Add to the loop annotations:
invariant left + right == arr.Length - 1

Keep the displayed bounds and processed-prefix/suffix invariants. Initialization establishes the added relation, the bounds, and both vacuous quantified conditions; the new assignment establishes res. During a continuing iteration, the sum relation identifies the tested endpoints as mirrors. After left increases by one and right decreases by one, the sum is unchanged, the bounds hold, and the tested equality proves the two newly covered quantified cases. Previously covered cases and res are unchanged.

For an early false return, left < right and left + right = N-1 imply left < floor(N/2). The observed mismatch is therefore a valid witness against the palindrome predicate. At normal exit, left >= right and the sum relation give left >= floor(N/2); the processed-prefix invariant covers every index in the predicate, so returning true is correct. On every continuing iteration right-left decreases by two; it is positive while the guard holds. Empty and singleton arrays skip the loop and have a vacuously true predicate.

This verifies the repaired obligations analytically for all nonnegative lengths, assuming the array is unchanged by the loop as displayed. It does not certify the exact repaired text with any Dafny toolchain. A version-pinned source file, command and verifier transcript are still needed for a tool-verified implementation. The prose should also match the chosen language version: function method is non-ghost in Dafny 3, whereas the paper describes Listing 1 as a non-executable ghost function [3].

Formal guarantees remain conditional on the model and specifications. The paper does not establish universal real-world safety or convergence of every proposed self-correction loop. Those stronger conclusions require evidence; the absence of such evidence is not treated here as a proved contradiction.

The car-key example on p.4 does not supply a complete transition system, initialization and precise safety assertion. The displayed locking guard allows locking when an owner is inside; whether this violates the intended lockout property depends on that property’s meaning and the full model. No reachable counterexample or verified correction is claimed. A complete PAT model and verification transcript would resolve this question.

It supplies neither a practical error rate nor a proof that formal methods are necessary and sufficient for each restricted task [4]. The cited v1 was not compared with v2.

The PMLR record lists the PDF and OpenReview but no separate software link. The inspected author publication entry links the earlier long preprint. This does not prove that no code exists elsewhere. # Appendix A. Actual independent calculation

The following Python source was saved and run as sources/0003/independent_checks.py. It evaluates an independent logical model of the printed predicates and the auxiliary sets/recurrence. No author program is imported or executed. Its complete JSON result is saved beside the script; the decisive values are also reported in Section 3.

Code:
"""Independent logical predicates; no author programs are imported or run."""
import itertools,json
from pathlib import Path
def palindrome(a):
    return all(a[i]==a[len(a)-1-i] for i in range(len(a)//2))
def predicates(a,l,r,result):
    n=len(a)
    bound=0<=l<=r+1<=n
    prefix=all(a[i]==a[n-1-i] for i in range(l)) if 0<=l<=n else False
    suffix=all(a[j]==a[n-1-j] for j in range(r+1,n)) if -1<=r<n else False
    return [bound,result is True,prefix,suffix]
a,l,r,result=[1,2,1],0,1,True
p=predicates(a,l,r,result)
specific={"array":a,"left":l,"right":r,"res":result,
 "displayed_invariants":p,"guard":l<r,"mismatch":a[l]!=a[r],
 "palindrome":palindrome(a),"branch_return":False,
 "postcondition":False==palindrome(a),"reachable_from_initialization":False}
assert all(p) and specific["guard"] and specific["mismatch"]
assert specific["palindrome"] and not specific["postcondition"]
counts={"invariant_states":0,"bad_original_false_return_VCs":0,
        "bad_strengthened_false_return_VCs":0,"bad_strengthened_true_return_VCs":0,
        "bad_strengthened_preservation_VCs":0}
for n in range(7):
 for a in itertools.product([0,1],repeat=n):
  for l in range(n+1):
   for r in range(-1,n):
    if not all(predicates(a,l,r,True)): continue
    counts["invariant_states"]+=1
    strengthened=(l+r==n-1)
    if l<r and a[l]!=a[r] and palindrome(a):
     counts["bad_original_false_return_VCs"]+=1
     counts["bad_strengthened_false_return_VCs"]+=int(strengthened)
    if strengthened and l>=r and not palindrome(a):
     counts["bad_strengthened_true_return_VCs"]+=1
    if strengthened and l<r and a[l]==a[r]:
     good=all(predicates(a,l+1,r-1,True)) and (l+1+r-1==n-1)
     counts["bad_strengthened_preservation_VCs"]+=int(not good)
assert counts["bad_strengthened_false_return_VCs"]==0
assert counts["bad_strengthened_true_return_VCs"]==0
assert counts["bad_strengthened_preservation_VCs"]==0
availability=[{"Monday","Tuesday"},{"Tuesday","Wednesday"},{"Tuesday","Thursday"}]
mutation=[{"Monday","Wednesday"},{"Tuesday","Thursday"},{"Monday","Thursday"}]
u=0
for n in range(31):
 assert u==2**(n+1)-(n+2)
 u=2*u+n+1
out={"countermodel":specific,"initial_res_false_violates_invariant":True,
 "finite_domain":"binary arrays of lengths0-6; all bounded index pairs",
 "finite_VC_checks":counts,"original_schedule_intersection":sorted(set.intersection(*availability)),
 "mutated_schedule_intersection":sorted(set.intersection(*mutation)),
 "recurrence_identity_checked_n":[0,30],
 "intentional_bad_algebra_at_n1":{"correct":4,"displayed_incorrect":5},
 "author_code_executed":False,"dafny_or_z3_verification_run":False}
base=Path(__file__).resolve().parent
(base/"independent_checks.json").write_text(json.dumps(out,indent=2),encoding="utf-8")
print(json.dumps(out,indent=2))
