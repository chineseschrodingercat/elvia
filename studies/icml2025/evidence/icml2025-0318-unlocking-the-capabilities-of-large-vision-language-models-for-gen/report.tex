Abstract: Static control-flow analysis establishes an unmatched-response label defect in the released inference example, and an exact table comparison identifies ambiguous dataset attribution in the timing results. These are assessed Minor. The appendix supports the validity of a 32-frame vote-based AUC; historical metric impact, causal attribution of prompt gains and explanation faithfulness remain unverified.\par

\section*{What the reported evaluation measures}
KFD produces a localization map and a continuous forgery score. The language model receives visual embeddings, forgery embeddings and an explicit textual KFD score. Appendix A.1 resolves an ambiguity in the main text: the language-model score for video \(v\) is \[s_v=\frac1{32}\sum_{j=1}^{32}\mathbf{1}\{\text{frame }j\text{ is parsed as fake}\}.\] This has 33 possible values. Its empirical AUC is the fraction of positive-negative video pairs correctly ranked, with half credit for ties. It is a legitimate, albeit quantized, ranking statistic; it is not necessarily the balanced accuracy of a single binary response. An exact reviewer calculation with positive scores \(16/32,24/32\) and negative scores \(1/32,8/32\) gives AUC one. Calling the paper’s use of AUC invalid merely because frame outputs are binary would therefore be incorrect. This score is a vote fraction, not a demonstrated calibrated posterior probability.\par
The KFD and full LVLM scores should also remain distinct. Table 3 reports KFD AUCs \(99.53,94.71,99.64,97.62,91.81\) and LVLM AUCs \(97.11,89.90,92.26,95.97,86.70\) on the same five listed datasets. The latter are lower throughout. The contribution is an interactive system with strong reported cross-dataset detection, not an established increase in detection accuracy caused by the language decoder. Appendix A.4 explicitly acknowledges this tradeoff.\par
\section*{Substantive findings}
Problem 1 (The released response parser can inherit a previous image’s label).  In `inference.py`, lines 94–112, the loop sets `pred` only inside a sequence of substring conditions. There is no per-image initialization or unmatched-response branch. This conflicts with Appendix A.1’s rule that an unmatched response is labeled real.\par
\paragraph*{Independent logical check.}\mbox{}\par
Take the response “The image is a genuine photograph.” It contains none of the tested strings: `pristine`, `deepfake`, capitalized `Yes` or `No`. If the previous image set `pred=1`, the current printed judgment remains fake; if the previous value was zero, it remains real. On the first image the name has not been assigned. This follows from the visible module-level control flow and does not depend on any model weights. A reviewer-written transition model of the six ordered conditions confirms outputs \((\text{unassigned},0,1)\) for previous states \((\text{unassigned},0,1)\). It does not import or execute the author script. The case-sensitive tests and order of overrides also differ from the prose’s lowercase keyword specification.\par
\paragraph*{Impact and bounded repair.}\mbox{}\par
This is Minor and limited to the released inference helper: its printed judgment is not a function of the current image response alone for unmatched text. Initializing the label to zero at each iteration implements the documented default and removes this state carryover. It does not solve every linguistic ambiguity; an explicit case-normalized parser with a documented negation/precedence rule and an unmatched-response count is needed for a reproducible evaluator. No author file was changed. The frozen source does not provide the 32-frame video AUC evaluation loop, so neither the frequency of unmatched benchmark outputs nor any resulting change to published AUC is established. The observed helper error must not be silently extrapolated to the historical evaluation.\par
Problem 2 (The dataset attribution in the timing table is inconsistent with the main tables).  Appendix Table 10, p. 14, is titled as a CDF2 comparison. Its AUC vector for CADDM, Ours-KFD, FAK-Owl and Ours-LVLM is \((85.68,97.62,69.84,95.97)\). Every entry instead matches that method’s CDF1 value in Tables 1 or 3.\par
For comparison, the corresponding CDF2 entries in those tables are \((93.88,94.71,60.85,89.90)\). The matching CDF1 vector and mismatching CDF2 vector are independently transcribed and compared in the check output, and the original Table 10 was visually checked. A caption error is a plausible explanation, but raw evaluation records are absent, so this review cannot determine which dataset was actually timed or replace the published entries. This is a Minor reporting defect: the claimed joint speed/AUC operating point has ambiguous dataset identity. Correcting the caption or the AUC column must be tied to the original run; no correction is certified here.\par
Related numerical differences need provenance rather than invented explanations. Table 7 gives Vicuna-7B DFD AUC \(84.26\), whereas Table 3 gives \(92.26\), an eight-point difference. Table 7’s mean \(86.25\) agrees with its own four entries to rounding, so this is not simply a bad mean. Table 6 also uses results different from the main FF++ training row. Different checkpoints or settings could explain these differences, but those distinctions are not stated sufficiently to reconcile them. They remain unresolved correspondence questions, not proof that the underlying measurements are false.\par
\section*{Knowledge, localization and explanation: bounded evidence}
The method’s external descriptions and reference-based training are scientifically relevant but not fully validated by the available release. Appendix A.1 lists rich pristine/fake descriptors and says their feature dimension is 4096. The inspected source constructs only the literal “real” and “fake” text inputs before combining each with a shared learned context; its image decoder maps 1280-dimensional patch features to 1024, while 4096 is the language-model embedding width. This is a concrete correspondence difference, not evidence that the historical model never used the listed descriptions. The acquired subset contains the inference path but not the full two-stage data-generation/training/evaluation pipeline. Historical configuration, descriptor selection and ROP training effects remain unverified.\par
The explicit KFD score is present in the published prompt and in the source generation path. Supplying a model prediction is not ground-truth leakage. However, the language model can obtain authenticity information from that scalar independently of fine-grained spatial embeddings. Table 5’s FPL ablation shows substantial reported gains, but does not separately quantify a score-only prompt, maps with the scalar removed, and all inputs together. Consequently, it supports the combined interface more directly than a causal claim that localized prompt features alone explain the classification gain. Such controlled comparisons would clarify the attribution; no outcome of those missing experiments is predicted here.\par
Figures 4–5 show attention/localization maps and selected textual descriptions. They support the ability to emit regional descriptions but provide no measured localization IoU, explanation faithfulness score or population-level dialogue accuracy. Figure 6 explicitly contains classification errors and unsupported descriptions despite its asserted correct locations. The multi-turn screenshots include repetition of a supplied forgery score and general facial-content statements. These are useful examples of interaction, but neither a highlighted face nor a repeated score establishes faithful reasoning about the artifact. No ground-truth masks or independent annotations were available for quantitative verification of the selected examples.\par
The real/fake mixture in Eq. (6) is an alpha-mask blend as written, whereas the prose calls the simulation Poisson blending. The full data-generation routine is not in the acquired subset, so this wording cannot identify which procedure generated the training pairs. Likewise, use of real FF++ images to synthesize training forgeries is disclosed; it does not mean that all training examples remain pristine. The paper’s DF40 description shares an FF++ source domain, so that experiment is principally cross-manipulation, distinct from the separate cross-dataset tests. No identity leakage is established without the actual split manifests.\par
\section*{Checked comparisons and remaining limits}
The independent script verifies Table 3 means \(96.662\) (KFD) and \(92.388\) (LVLM), Table 8 means \(89.9975\) without ROP and \(90.815\) with ROP, and selected ablation differences. Table 8’s ROP effect is not positive in every dataset: DFDC changes from \(79.31\) to \(79.12\). Table 1 likewise does not support universal superiority: CDF2 AUC is below LAANet, DFDC below UDD/RepDFD, and DFDCP below RepDFD. Table 2 contains InSwapper and FS-vid2vid exceptions. The results can support competitive or selected-dataset improvements without an across-all-methods, across-all-datasets claim.\par
Some baselines have missing columns or different fine-tuning protocols, as their captions disclose; averages across different available datasets are not a matched comparison. No independent split audit, seed variability, evaluator validation, raw-score audit or pretrained-data-overlap check was performed. These limitations leave empirical strength and explanation faithfulness open for further evidence, while the two verified local defects justify the Minor assessment. Scientific adjudication remains pending.\par
