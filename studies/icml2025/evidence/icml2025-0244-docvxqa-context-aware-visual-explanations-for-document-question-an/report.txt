Abstract: The practical information-bottleneck-inspired objective is presented as a heuristic, not a proved mutual-information identity. No substantive error was established in that mathematical interpretation or the displayed preference-count arithmetic. Three implementation/specification concerns are established in the pinned public source: reference answers enter validation-mask construction, training never clears accumulated gradients, and matrix norms implement different penalties from entrywise sparsity and anisotropic total variation. The reference-conditioned route must be distinguished from annotation-free evaluation; the paper also explicitly uses an answer-conditioned ColPali baseline. The demonstrated optimizer and regularizer discrepancies are local to these heuristic choices. These findings are assessed as Minor in that bounded scope; the intended evaluation protocol and historical table correspondence remain Needs Evidence.

# Checked reasoning and necessary interpretation

Let \(T=X\odot M\). Equation (2), p. 4, uses \(I(T;Y)=H(Y)-H(Y\mid T)\) with fixed target distribution. For a predictor \(q_\theta\), \[\mathbb E[-\log q_\theta(Y\mid T)]
 =H(Y\mid T)+\mathbb E_T D_{\mathrm{KL}}(p(Y\mid T)\Vert q_\theta(Y\mid T)).\] Cross entropy is therefore an upper surrogate, with a model/optimization gap. The paper uses an approximation sign. Section 3.3 explicitly says the attempted direct mutual-information estimator did not work as expected and substitutes L1 plus continuity regularization. It would be incorrect to attribute to the paper an exact equality between that penalty and \(I(X;T)\).

These losses encourage compact masks and predictive utility; they do not prove global minimal sufficiency or causal faithfulness. Section 4.1 measures the answer model’s performance on masked images. The authors themselves recognize (p. 8) that retaining a number can permit an answer while omitting the context identifying it as the requested total. Human ratings add a separate perceptual criterion. This bounded interpretation is supported; a theorem of faithful recovery of internal reasoning is not supplied.

# Problem 1: Validation masks receive reference-answer information

Assessment: Minor for the evaluator/protocol mismatch under an annotation-free reading; the intended conditioning and historical impact need evidence. Figure 2 and Section 3.1 (pp. 3–4) describe a question/document input that produces a mask and then an answer. Section 4.1 (p. 6) describes comparing the subsequent predicted answer with ground truth. The pinned validation route instead admits ground truth before constructing the mask.

## Static evidence and dependency

In , the dataset’s reference answer is assigned to ; lines 174–177 tokenize it into . In , shifts those labels into decoder input IDs, obtains cross attentions, aggregates them into mask-head features, thresholds the mask, and only then generates a masked-image answer. The evaluator is called after each epoch and its ANLS selects the best checkpoint (lines 247–260).

Thus the validation mask is a function \(M_\theta(X,Q,Y_{\rm ref})\), whereas an annotation-free deployment mask must be obtainable from \(X,Q\) and model-generated information. For a multi-token reference, the shifted decoder input contains reference tokens after the start symbol. The aggregation includes those later positions whenever its selected length exceeds one; reference-conditioned decoder features can therefore affect the mask. This is a traced dependency, not a measured estimate of score inflation.

The standalone has the same reference-conditioned route, but also a misspelled keyword. We do not claim that file executes unchanged. The training evaluator uses the correctly spelled keyword, so the dataflow finding does not depend on repairing the standalone typo.

## Counterevidence and impact

The demo notebook first generates a full-image answer and then tokenizes that prediction to construct the mask (code cells 11 and 13). It supplies an intended annotation-free route and demonstrates that reference conditioning is not unavoidable. If a prediction equals the reference, the token sequences can coincide; no strict score inflation on every example is claimed. Explaining an explicitly supplied answer is also a legitimate conditional task, but its results must be identified as such rather than substituted for question/document-only performance.

Section 4.2 (p. 6) explicitly feeds ColPali a concatenated question and answer. It does not identify that answer here as ground truth or a first-pass prediction. This is material counterevidence to treating every evaluated explanation as necessarily answer-free. The static data dependency is established, but a stronger accusation that all answer conditioning violates the intended task is unsupported. The public validation implementation therefore does not by itself establish annotation-free masked-answer sufficiency. No archived run configuration or checkpoint-to-table mapping establishes that Table 1 used these exact bytes. Re-evaluation with generated first-pass answers, retained raw outputs, and a bound historical version is necessary to resolve that question. Replacing reference decoder inputs with generated ones is a candidate repair; no empirical repair has been verified.

# Problem 2: Training accumulates stale gradients across optimizer steps

Assessment: Minor; released training source. The method optimizes the combined loss in Eq. (3); Appendix A.3 specifies AdamW. In , AdamW is constructed at line 46, and each minibatch calls then at lines 133–134. The loop and epoch driver never call , assign cleared gradients, or invoke a clearing hook. The separate backbone fine-tuning script does clear gradients, but is not called by this training routine.

PyTorch backward adds to gradient buffers; optimizer stepping does not perform that reset [Retained latex: \cite{grad}]. Consequently, after initially empty gradients, the second step receives \(g_1+g_2\) rather than \(g_2\), and subsequent buffers retain still older gradients evaluated at earlier parameter values. This is not ordinary deliberate accumulation over a fixed microbatch group with one later step: the code steps every minibatch and never resets.

For a scalar initialized at zero, take two minibatch losses \(L_1(w)=w\), \(L_2(w)=-w\). With Adam moments initially zero, \(\beta_1=0.9\), \(\beta_2=0.999\), and \(\epsilon=10^{-8}\), the independent calculation gives

Second step | Gradient supplied | Adaptive update / learning rate

Reset for each minibatch | \(-1\) | \(+0.0526315784\)

Released no-reset pattern | \(0\) | \(-0.6700582447\)

Both have the same first-step weight, so the second-step decoupled weight-decay contribution is identical and cannot remove the discrepancy. This diagnostic demonstrates a changed optimization update, not a prediction of DocVQA accuracy.

An undocumented intention to use cumulative gradients would define a different optimizer and require justification; none was found in the inspected route. Resetting at the intended accumulation boundary restores ordinary minibatch semantics locally. Historical use, retraining effects and repaired metrics remain unverified.

# Problem 3: The released minimality loss uses induced matrix norms

Assessment: Minor; released objective implementation. Section 3.3 (p. 5) describes mask sparsity and anisotropic total variation: entrywise absolute mask values and horizontal/vertical differences. But calls with , and line 199 applies to a two-dimensional token-by-batch matrix. These are induced matrix 1-norms, namely maximum absolute column sums [Retained latex: \cite{norm}].

For a fully valid batch with \(B\) masks and \(N\) unpadded tokens, the sparsity term is \[L_{\rm released}=\frac{10}{BN}\max_b\sum_{n=1}^{N}|M_{bn}|,
 \qquad
 L_{\rm entrywise}=\frac{10}{BN}\sum_b\sum_n|M_{bn}|.\] Use \(B=N=2\), with masks \((0.8,0.8)\) and \((0.1,0.1)\). All entries are strictly inside the sigmoid range. The released term is 4, versus 4.5 for the scaled entrywise mean. Since the first sample uniquely maximizes the sum, the released sparsity gradient for both coordinates of the second sample is zero, versus 2.5 for each under the entrywise expression.

Likewise, take a batch of \(B=2\) identical, fully valid, unpadded \(2\times3\) masks, each equal to \[M=\begin{pmatrix}0.1&0.9&0.1\\0.1&0.9&0.1\end{pmatrix},\] horizontal absolute differences have entrywise sum 3.2 but maximum column sum 1.6; vertical differences vanish. With the code’s common denominator \(6-1\), the per-mask terms and their batch means are 0.64 and 0.32 respectively. Taking two masks is necessary here: the implementation’s unqualified would remove the batch axis for \(B=1\), so this witness uses \(B=2\) to retain the required three-dimensional tensor. The discrepancy does not depend on padding or a boundary mask value.

Both losses can still encourage some regularity; this is not proof of failed learning. A deliberately chosen matrix norm is a possible alternative regularizer, but is not the described entrywise penalty, and it changes which samples/edges receive gradients. Explicit absolute sums with a documented normalization would implement that intended penalty. Only the identities and finite examples were verified; no repaired training run or historical-table effect is established.

# Empirical checks, overall impact, and state

The 42-participant study uses ten images and shows ground-truth answers before ratings (pp. 8–9). It measures perceived context and clarity with answers disclosed; it does not directly measure unaided answering or a causal change in calibrated trust. The separate preference study reports \(163/252=64.6825\%\), consistent with 64.7%. Under independent Bernoulli trials, the two-sided exact binomial value is \(3.65\times10^{-6}\); under independent participants, all 12 favoring the method gives a sign-test value \(2/2^{12}=0.0004883\). These are conditional diagnostics, not a validation of independence. The participant-by-item response matrix and interval construction are unavailable, so uncertainty under repeated judgments remains Needs Evidence.

Table 1 openly shows a PFL-DocVQA unmasked accuracy change from 0.80 to 0.57: 23 percentage points, or 28.75% relative. This should accompany the prose description of a slight decrease. On DocVQA the proposed masked setting and ColPali baseline tie at accuracy 0.38 and pixel ratio 0.23, with ANLS 0.54 versus 0.50. No hidden arithmetic contradiction or universal strict dominance is established. Appendix A says postprocessing is applied to all compared methods.

The supported overall assessment is Minor. The established results are a conditional evaluator/protocol mismatch and local discrepancies in heuristic optimizer and regularizer definitions; no invalid core derivation or material failure of the paper’s core explanation claim is demonstrated by these checks. This scope, rather than a requirement to measure benchmark loss or authenticate a historical commit, determines the severity. The intended answer-conditioning protocol and historical empirical impact remain unresolved.
