# Contribution and checked objective direction

HMR-Scorer learns relative reconstruction quality from perturbed poses using geometric error metrics. It ranks generated mesh candidates to create synthetic winner/loser pairs; diffusion preference optimization then adapts a base reconstruction model. The scorer is also used to filter noisy training labels. These are automatically generated metric/scorer preferences, not demonstrated human-annotated judgments.

For fixed positive \(\gamma=\beta T\omega(\lambda_t)\), write \[D=(E_{\theta,w}-E_{{\rm ref},w})
  -(E_{\theta,l}-E_{{\rm ref},l}).\] Equation (5), p. 5, is \(-\log\sigma(-\gamma D)
=\operatorname{softplus}(\gamma D)\), hence \[\frac{\partial L}{\partial E_{\theta,w}}
 =\gamma\sigma(\gamma D)>0,\qquad
 \frac{\partial L}{\partial E_{\theta,l}}
 =-\gamma\sigma(\gamma D)<0.\] Gradient descent lowers the winner residual relative to the loser. This sign check found no issue. The inspected pairing path preserves winner/loser ordering, uses coupled noise/timesteps, and freezes the reference networks.

The KL-regularized reward formulation motivates a density-ratio preference objective; the diffusion loss is its denoising surrogate. This review does not promote that surrogate into an exact marginal-likelihood identity. The external Diffusion-DPO derivation was not independently audited. Its latent-trajectory and weighting assumptions would be needed for a complete equivalence claim, which is not invented here.

# Problem 1: the release optimizes separate component losses

Rating: Minor, current-release scope. Locations: p. 3, Section 3.2; p. 5, Eq. (5); `ADHMR/lib/models/loss.py:96–146`; `ADHMR/lib/runners/hyponet.py:174–184`.

The paper combines joint/swing and twist representations into one data sample and places one log-sigmoid around the total squared-residual difference. The release separately averages joint and twist errors, computes separate log-sigmoid losses, and adds them. A rescaling of component means versus sums cannot make these two nonlinear objectives equivalent.

Let \(d_j,d_t\) be the model-minus-reference winner/loser error differences averaged over joint and twist coordinates. In the shipped 29-joint/23-twist configuration there are 87 joint coordinates and 46 twist coordinates. With all visibility masks one, the paper’s total difference is \(87d_j+46d_t\), while the released loss has the form \[\operatorname{softplus}(c d_j)+\operatorname{softplus}(c d_t),
 \qquad c=\beta_{\rm dpo}/2>0.\] Take any \(a\ge0\). Set reference squared residuals to zero, model winner joint errors to zero, model loser joint errors to \(46a/87\) on each coordinate, model winner twist errors to \(a\) and model loser twist errors to zero. These are nonnegative squared errors. Then \[d_j=-46a/87,\quad d_t=a,\quad 87d_j+46d_t=0.\] The single combined loss stays \(\log2\) for every \(a\) and every positive \(\gamma\). For normalized \(c=1\), the release’s split loss is:

\(a\) | Combined loss | Split loss

0 | 0.693147 | 1.386294

1 | 0.693147 | 1.776587

2 | 0.693147 | 2.425055

The nonconstant change, not merely the additive difference at zero, proves inequivalence. Both the auxiliary and parent independently computed these values without author imports.

The split loss imposes component-level preferences even when total candidate advantage cancels. It can be an intentional alternative objective; it is not necessarily inferior. The required correction is to identify which objective generated the results and either combine weighted components before one log-sigmoid or explicitly document/evaluate the separate form.

The auxiliary also found an active image-condition optimizer in the release despite the paper’s denoiser-only description. Selecting evaluation mode does not itself freeze parameters. These observations strengthen the need for exact historical configuration binding, but do not establish that the reported training used the later implementation or that benchmark scores are false. No replacement training recipe was run or validated.

# Problem 2: scorer test mode falls through without a return

Rating: Minor, release reproducibility. Locations: ; .

The test entry calls the scorer with mode `’test’` and then reads `model_out[’img’]`. The forward method directly returns outputs for `’clean’` and `’dpo’`. Its final output dictionary and return are nested inside `if mode == ’train’`, with no later test or unconditional return.

Assuming preceding model/tensor operations succeed, the test call therefore returns `None`, and the entry point cannot access the expected dictionary. The parent directly read the source and independently parsed its syntax tree. The only return branches in the method are at lines 286, 307 and 335, conditioned on clean, dpo and train respectively. Parsing and static reasoning did not execute the author program.

A suitable test-mode dictionary/return would fix this local path. No checkpoint or repaired author code was run. The defect is demonstrated for the pinned release, not for the historical scorer experiments, which could have used another implementation.

# Problem 3: correlation signs need an explicit reporting convention

Rating: Minor reporting inconsistency; actual ranking direction Needs Evidence. Locations: p. 4, Eq. (2) and scorer description; p. 5, Table 1 and caption; `HMR-Scorer/data/dataset.py:82–112`.

The scorer assigns higher values to better meshes, and its pairwise label is one when the first candidate has lower reconstruction error. A perfect quality score therefore correlates negatively with raw error: errors \((1,2,3)\) and scores \((3,2,1)\) have Pearson and Spearman correlation \(-1\).

Table 1 nevertheless reports positive PLCC/SRCC values with upward arrows and describes correlations with reconstruction errors. For example, its PVE entries are \(0.63/0.62\) for GTA-Human and \(0.66/0.64\) for DNA-Rendering. The release calls signed Pearson and Spearman functions directly on raw score and positive error arrays, without an explicit negation or absolute value in that routine.

A benign omitted convention—negative-error correlation or magnitude—could reconcile the table. A later source mismatch is also possible. The existing evidence therefore requires clarification, not a claim that the trained scorer actually rewards bad meshes. Signed evaluation arrays and the exact reporting transformation are needed. The caption’s PA-PVE versus header’s PA-MPJPE naming also needs resolution. No scorer prediction was independently evaluated.

# Needs Evidence: global cleaning calibration

The ranking loss compares candidates within the same input image. Adding an arbitrary image-dependent offset \(b(I)\) to all its candidate scores leaves every pairwise difference and the ranking loss unchanged. A single threshold across images need not be invariant.

For example, image-one scores \((2,1)\) and image-two scores \((-1,-2)\) each yield within-image preference probability \(\sigma(1)\approx0.73105858\). Offsets \(-10\) and \(+10\) change the score sets to \((-8,-9)\) and \((9,8)\) without changing either preference. Their retention at a raw threshold \(0.6\) reverses. Applying a monotone sigmoid does not remove the unidentified image-dependent offset.

This demonstrates that within-image ranking alone does not identify a globally calibrated cleaning threshold. It does not prove that a particular trained network lacks useful calibration or that the measured cleaning improvements fail. The paper supplies downstream empirical evidence, while the exact training/cleaning pipeline and calibration records remain unavailable. The inspected release returns raw scores in clean mode despite other paths computing a sigmoid score; resolving which quantity and threshold generated the reported cleaned set requires historical artifacts.

# Empirical checks and counterevidence

Page 7 explicitly reports minimum MPJPE and PVE over \(M\) generated candidates. These are disclosed oracle set-quality metrics. There is no supported concealed-oracle allegation. They do not alone establish the error of a single deployable prediction selected without ground truth. Page 8 identifies target-benchmark training sets for finetuning; shared dataset names are not by themselves evidence of test leakage.

Selected same-\(M\) arithmetic supports the reported improvements. On 3DPW at \(M=100\), HypoNet to ADHMR decreases PVE by 8.0 mm, MPJPE by 5.8 mm and PA-MPJPE by 4.1 mm. These are table arithmetic checks, not rerun evaluations.

The claim that ADHMR(ITW) with \(M=10\) outperforms HypoNet with \(M=200\) requires a metric qualifier: the listed PVE and MPJPE improve, but PA-MPJPE is 37.1 versus 36.1 mm, worse by 1.0 mm. The cleaning table likewise has a disclosed exception: SMPLer-X EHF PA-PVE rises from 51.0 to 51.4, while 20 of 21 inspected model/metric cells improve. These bounded qualifications do not refute the matched-\(M\) gains or imply fabricated results.

The scorer’s perturbed-pose evaluation distribution differs from actual generated candidates and noisy pseudo-labels. Tail-ranking reliability and calibration for those downstream uses are not established by aggregate correlations alone. The supervised-extra-data baseline is relevant counterevidence, but does not isolate every effect of external data versus the preference objective. Raw predictions, per-seed results, exact checkpoints and configurations would be needed for stronger causal or uncertainty conclusions.
