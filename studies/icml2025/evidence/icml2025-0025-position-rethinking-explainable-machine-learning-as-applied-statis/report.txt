# 3. Problem 1 - A closest counterfactual need not exist

Source claim and location. Under Definition 2.3, p. 2, statistics of functions have vector-valued outputs. Section 2.2, example 9 on p. 3, lists the nearest point with a different prediction as an example, using the following argmin. The missing step is ensuring that the feasible set contains a distance minimizer and that the expression selects one point when ties occur.

\[\operatorname*{arg\,min}_{z:\,f(z)\ne f(x)}\|x-z\|_1.\] Complete counterexample. Set d = 1 and f(z) = 1{z > 0}, and explain x = -1. If a distribution argument is required, fix D to the uniform distribution on [-2,2]; it does not affect the displayed optimization. This is an ordinary measurable binary threshold classifier, with x inside the data support. We do not exploit a nonmeasurable function, infinite loss, or regression output.

\[f(-1)=0,\qquad \{z:f(z)\ne f(-1)\}=(0,\infty),\qquad |-1-z|=1+z\quad(z>0).\] The feasible set is nonempty, yet no candidate is closest. For every feasible z, the point z/2 is also feasible and has strictly smaller distance. Meanwhile the feasible sequence z_n = 1/n has distances 1 + 1/n converging to 1. Thus the infimum is 1, but it is not attained, and the argmin is empty. The same problem remains if candidates are restricted to the distribution support: the feasible set becomes (0,2], with the same unattained infimum.

\[\inf_{z>0}(1+z)=1,\qquad \operatorname*{arg\,min}_{z>0}(1+z)=\varnothing.\] This contradicts the unrestricted use of the expression as a point-valued example. It does not contradict the claim that properly specified counterfactual algorithms can be useful statistics, and no later theorem or experiment in this position paper depends on the unrestricted optimization.

Strongest alternative reading and severity. The example may be intended as a sketch with existence, finite numerical precision and tie handling understood. Those assumptions are often supplied in implementations. However, this failure occurs for a routine classification boundary and should be explicit when the example motivates a formal domain and output type. Judgment: Minor, a local well-posedness gap.

Repair and its verification. Specify a nonempty closed target region C and an output-selection convention. In finite-dimensional Euclidean space, the continuous distance to x attains its minimum on nonempty closed C: choose any point in C, restrict attention to points no farther than that point, and minimize on the resulting closed bounded, hence compact, nonempty set. The minimizing set can still contain multiple points, so a fixed tie rule or a set-valued output must be declared.

For the displayed counterexample, impose a positive margin z >= epsilon > 0. The unique minimizer is z = epsilon, since 1 + z is strictly increasing. At epsilon = 1/10, the repaired optimum is 1/10, its label is 1, and its distance is 11/10. This repair changes the feasible set transparently; merely flipping a threshold convention from strict to non-strict is not a general solution because another class can remain open. Alternatively, return a specified approximate counterfactual and label it approximate. The existence proof and special-case arithmetic verify the proposed mathematical repair; no algorithm implementation was patched or tested. Adoption was not requested.

# 4. Positive check - Zero attribution can coexist with local dependence

Section 5.2, item 1 on p. 6, warns against treating zero feature attribution as irrelevance. The conditional-SHAP formula on p. 3 supports a direct one-feature verification. Take X uniform on [-sqrt(3),sqrt(3)], f(t) = t squared, and x = 1. The function is smooth, the distribution is bounded, all needed moments are finite, and x is interior to the support. For one feature, the only coalition difference is f(x) minus the background expectation, using the natural fully observed conditional value f(x).

\[\mathbb{E}[f(X)]=\frac{1}{2\sqrt{3}}\int_{-\sqrt{3}}^{\sqrt{3}}t^2\,dt=1,\qquad \phi_1=f(1)-\mathbb{E}[f(X)]=0.\] \[f'(1)=2,\qquad f(1+h)-f(1)=2h+h^2>0\quad\text{for }0<h<\sqrt{3}-1.\] The perturbed inputs remain within the data support. Thus this is not an out-of-distribution artifact. At h = 1/10, the exact change is 21/100 despite zero attribution. The result supports the target’s warning: a signed baseline-relative score does not certify local insensitivity. It does not establish that SHAP is useless, nor that every attribution method fails for every task.

Selected source comparison. Bilodeau et al.’s arXiv:2212.11870v2, §§3.1-3.2, places its impossibility result under explicit model-class richness and baseline/domain conditions and completeness/linearity of the attribution. Those assumptions should not be dropped when summarizing the general theorem. The simple calculation above is independently derived and does not depend on re-proving that theorem. The inspected source is the 11 April 2023 preprint version, not an asserted byte-identical copy of the final PNAS article cited by the target. [S2]

# 5. Other checks and scope clarifications

Target location | Evidence and bounded assessment

Definition 2.3 p. 2; footnote 2 p. 3; §7 p. 8 | The authors explicitly replace function space by parameter space for methods depending on network parameterization. Different internal explanations for identical input-output functions would illustrate that acknowledged caveat, not expose an unacknowledged contradiction.

Definitions 2.1-2.3, pp. 2-3 | Individual examples require ordinary domain conditions: finite moments, differentiability, fixed background distributions and conditional-expectation conventions. Outcome-dependent performance/fairness also needs labeled evaluation information. These are scope conditions; no separate major formal failure is alleged.

§4.2 p. 5: anchors | The primary Anchors paper defines conditional prediction precision under a specified perturbation distribution and maximizes coverage subject to a confidence/precision condition (PDF p. 4, Eqs. 2-4). Read the target’s similarity language within that rule-and-distribution scope, not as a universal metric-based individual-fairness guarantee. [S3]

§5.1 pp. 5-6: p-values and confidence intervals | The p-value discussion agrees with the ASA distinction between a tail probability under a statistical model and the posterior probability of a hypothesis. Frequentist interval coverage is a repeated-sampling property; it does not supply a posterior probability for a fixed realized interval. No defect found in the inspected explanatory point. [S4]

§§4.3, 6 and 9: interpretation, trust and benchmarking | The broad prevalence and utility judgments were not independently measured. They remain argued positions. The paper’s acknowledgment that explanations can help debugging and that some methods have clear interpretations should be retained.
