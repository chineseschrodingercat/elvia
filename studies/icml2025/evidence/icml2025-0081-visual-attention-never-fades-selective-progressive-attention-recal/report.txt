# 3. Mechanism, assumptions and checked equivalence

Let a_j be the ordinary softmax attention coefficient in one head, V_j its cached value, alpha > 1 the gain, and c_j the number of completed selections before the output being calculated. With the same c_j and update schedule on both sides, repeated cache scaling gives the exact identity below.

\[\sum_j a_j\left(\alpha^{c_j}V_j\right)=\sum_j\left(a_j\alpha^{c_j}\right)V_j.\] For a=(1/4,3/4), V=(2,4), alpha=2 and c=(1,0), both expressions equal 4. If one additionally renormalizes the coefficients, the result is 16/5. That is a different operator: Eq. (8), p. 6, does not require this additional normalization. Consequently, a purported counterexample based on demanding normalization would misrepresent the source claim. Exact Fraction arithmetic and its output are retained in `agent_claim_check.py` and `agent_claim_calculation.json`.

The pre-update count in Eq. (7) sums k<i, while adjacent prose describes selecting and updating during step i. The released implementation explicitly copies the previous selection at layer 0 (`attn_util.py`:42-48,151-156), scales cached values before cache update, and records the current selection later (210-223). This implements the historical-count reading and avoids a circular requirement that a layer-20 selection already affect earlier layers in the same pass. The prose could state this timing more clearly; no consequential failure was demonstrated.

Relative activation is computed against the previous exponential moving average before that average is updated (`attn_util.py`:203-223). The current code uses >= at the threshold, whereas Eq. (6) uses >; no evidence connects this boundary convention to a material result. The ordinary softmax matrix is unchanged by scaling V when Q and K are held fixed, but downstream layers and later steps can change Q and K. Figure 7 therefore cannot be refuted merely by holding all Q/K states fixed. Reproducing that figure would require the actual measurement script and traces.
