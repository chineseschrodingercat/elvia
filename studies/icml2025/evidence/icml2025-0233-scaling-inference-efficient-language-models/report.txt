# Formulation and numerical checks

Equation (4), p. 5, fits \[L(N,D,R)=(E+AN^{-a}+BD^{-a})(1+\varepsilon R^a),
\qquad R=d_{\rm model}/n_{\rm layers},\] after the exponent tying described in Section 3.2. The inspected source implements this expression; its local variable named `gamma` denotes the multiplicative coefficient \(\varepsilon\), not a distinct exponent. Latency is separately profiled for candidate architectures, and downstream scores are measured after candidate training. The procedure therefore does not claim that training loss uniquely determines downstream accuracy or that this fitted expression is a hardware-independent latency theorem.

The parent checked Table 2 (p. 7), including its typeset rendering: \(3.61/1.96=1.8418367\), supporting the rounded \(1.8\times\) speed ratio between Morph-1B-v1 and Morph-1B in the specified timing setting. Both listed mean downstream accuracies are 0.52. This arithmetic confirms the table’s internal comparison, not equality of taskwise performance or statistical equivalence. An auxiliary independently reimplemented the fitted equations using literal data extracted statically from the released fitting scripts, without executing those scripts. The main fit contains 27 observations; the pooled evaluation contains 76, including those 27 fitting points. Figure 8 explicitly distinguishes fitting dots from test crosses. The independent pooled results reproduce its rounded metrics: Chinchilla MSE \(0.0032962\) and \(R^2=0.9895123\), versus shape-law MSE \(0.00055356\) and \(R^2=0.9982387\). Removing the 27 fitting observations leaves 49 held-out observations:

Chinchilla | 0.00414076 | 0.98431685

Shape-dependent | 0.000650879 | 0.99753479

Thus the approximately \(6.36\)-fold MSE improvement survives that separation. The four larger-model points yield maximum relative prediction errors of about 1.146% and 4.096%, respectively, consistent with the stated main comparison. These are calculations from released numeric records, not fresh language-model training or proof that those records match the original run logs.

# Scope clarifications

The no-overtraining ablation deserves a precise interpretation. If \(D=cN\) exactly and the exponents are tied, then \[AN^{-a}+B(cN)^{-a}=(A+Bc^{-a})N^{-a}.\] Only the combined coefficient is identifiable on that design: \((A,B)\) and \((A+\delta,B-\delta c^a)\) give the same values. The parent verified this identity analytically and with a small independent finite calculation. Actual released counts vary within nominal size groups, so exact degeneracy is not asserted for that concrete dataset; the calculation explains the nearby confounding. The main fit includes longer training runs, and the paper explicitly reports deterioration when they are removed. This observation therefore does not refute the main fitted comparison.

Selected source checks also revealed that nominal size labels are approximate and that profiling scripts and their defaults cover different timing tasks. Consequently, current default commands cannot be equated automatically with every historical plot. No measured timing bias was established from the inspected source.
