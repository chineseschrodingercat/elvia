\subsection*{2. Summary and scientific dependency}
The paper’s core contributions include a reproducible benchmark with programmatically checked passing criteria and guidance on which metrics measure fidelity or diversity [E1, pp. 1-2, 5-9]. The released default path computes recall cover under the key used for precision cover, and vice versa. Those keys then select different fidelity/diversity criteria and determine the table labels. An independent exact finite calculation demonstrates distinct intended and released named outputs under both the paper’s hyperparameters and the release’s defaults.\par
This is a demonstrated defect in an advertised central implementation, not an inference from a missing file or an unused helper. It supports Major at that contribution level. It does not establish which code generated every number in the published Tables 3-4. That historical provenance question remains unresolved. Other failure cases and the broad argument for more careful metric evaluation are not refuted by this finding.\par
Separately, the PDF reverses the cross-neighbour count inequalities in Eqs. (11)-(12). The released comparison uses the correct direction, so the printed error is assessed separately rather than being assumed to corrupt the experiments.\par
\subsection*{3. Definitions and assumptions}
Let R be the real embedded sample and G the generated embedded sample. For a sample point x in S, let b\_S(x) be the distance to its k-prime-th nearest neighbour in S, excluding x itself. Define a ball using distance at most b\_S(x). With k positive, the intended empirical cover scores are:\par
- Precision cover PC: the fraction of g in G whose G-neighbour ball contains at least k points of R.\par
- Recall cover RC: the fraction of r in R whose R-neighbour ball contains at least k points of G.\par
These orientations and the “at least” comparison are specified in Cheema and Urner’s Definition 2, Eqs. (3)-(4), physical PDF p. 4 [E4]. They also match the orientation of the target paper’s sums, after correcting its inequality signs.\par
The finite checks below use distinct, one-dimensional real-valued observations, n = m = 1000, positive real-sample variance, and valid neighbour counts less than n. They test deterministic metric definitions and implementation semantics, not an asymptotic probabilistic theorem. A common affine transformation with positive scale preserves every nearest-neighbour radius and cross-ball membership.\par
\subsection*{4. Problem 1: the released benchmark swaps precision and recall cover}
Judgment: Major, scoped to the core public implementation.\par
\subsubsection*{Source claim and exact path}
The paper identifies C-Prec as fidelity and C-Rec as diversity in Table 1 (p. 4), and bases the evaluations and practitioner guidance on that distinction. Its publisher-linked README says the released workflow produces Tables 3 and 4 [E1-E3].\par
The inspected path is:\par
1. `sanity\_checks/gaussian\_mixture.py` constructs a metric computer with real data, then calls `compute\_metric` with synthetic data.\par
2. `metrics/metric\_computer.py::MetricComputer` fits StandardScaler on the real data and applies that same transformation to both sets.\par
3. `metrics/precision\_recall\_cover/precision\_recall\_cover\_computer.py::PrecisionRecallCoverComputer.compute\_metric` explicitly sets P to scaled real data and Q to scaled synthetic data.\par
4. Its first loop counts sufficiently covered real-centred balls and returns that average as `precision\_cover`. Its second loop counts sufficiently covered synthetic-centred balls and returns that average as `recall\_cover`.\par
5. `experiment\_config.py::metric\_types` maps these keys to fidelity and diversity, respectively. `sanity\_check\_criteria.py::CriterionSeparatorByMetricType` selects the corresponding tests. `aggregate\_pass\_fail\_tables.py::print\_metric\_names` prints the keys as C-Prec and C-Rec without reversing them.\par
Thus the computed quantities are the opposite of the intended named measurements. The inspected class is the one registered in the benchmark; the finding does not depend on its unused duplicate function.\par
\subsubsection*{Complete independent finite check}
Choose:\par
`R = \{4i : 0 <= i < 500\} union \{100000 + 4i : 0 <= i < 500\}`\par
`G = \{2j + 1 : 0 <= j < 1000\}`\par
The generated sample covers the first real cluster and omits the second. Each set has exactly 1000 distinct finite points. R has nonzero variance. Cross-set distances are odd integers while within-set radii are even, so no cross-ball boundary tie occurs. StandardScaler applies a common translation and positive rescaling in one dimension; every comparison remains unchanged.\par
The target paper prescribes k-prime = ceil(log(1000) + 6) = 13 and k = ceil(13/3) = 5. The released constructor instead uses a 15-neighbour radius with k = 5. The discrepancy below holds for both:\par
Radius convention | Cross-counts at retained real points | Cross-counts at omitted real points | Cross-counts at generated points\par
Printed defaults: k-prime = 13 | -28 |  | -7\par
Released defaults: k-prime = 15 | -32 |  | -8\par
Every generated-centred ball contains at least five real points, so PC = 1. Exactly 500 of the 1000 real-centred balls contain at least five generated points, so RC = 1/2. The released dictionary, by its statically established semantics, reports precision\_cover = 1/2 and recall\_cover = 1.\par
The reviewer-authored standard-library script `code\_audit/independent\_cover\_check.py` enumerates integer distances and counts. Its saved JSON records these outputs. It never imports or invokes author code [E5].\par
\subsubsection*{Counterevidence, alternatives and precise consequence}
Exchanging the arguments could compensate for the reversal, but the actual callers pass real then synthetic, and the base class and local assignments confirm that order. A subsequent relabelling could also compensate, but the inspected aggregation and printing paths preserve the keys. The correct inequality inside `PR\_Cover\_Indicator` does not fix the orientation error. Nor does the different neighbour-radius rounding: the witness works under both choices.\par
The wrapper and bundled source acknowledge upstream code. This report attributes the observed behaviour to the acquired release and does not assign personal responsibility for its origin. Cached notebook outputs are historical evidence, not proof of the exact code used for the published PDF.\par
The dependency is direct: wrong named scalar -> wrong fidelity/diversity branch -> wrong interpretation of a passing or failing test. For example, the mode-dropping test expects fidelity to remain horizontal and diversity to fall. Routing the two measurements oppositely changes which property is being assessed. It invalidates the release’s claim to evaluate the two specified cover metrics under their correct roles, even if other metric columns and the broad position remain useful.\par
\subsubsection*{Scoped repair}
Return the generated-centred average as precision cover and the real-centred average as recall cover, then regenerate criterion decisions and tables from correctly named raw measurements. This mapping restores PC = 1 and RC = 1/2 in the exact witness. It is analytically verified for the naming defect; the author implementation was not modified or executed. Matching the stated radius policy and reassessing historical outputs are separate tasks.\par
\subsection*{5. Problem 2: printed cover definitions reverse the inequality}
Judgment: Minor, limited to the documented metric specification.\par
Location. Appendix A, physical p. 13, Eqs. (11)-(12), visually inspected. Each indicator uses a cross-count at most k, whereas the intended method requires at least k [E1, E4].\par
For a complete check, use r\_i = i/1000 and g\_i = 10 + i/1000, i = 0,…,999. Both sets contain 1000 distinct points. With the paper’s k-prime = 13 and k = 5, every within-set radius is at most 13/1000, whereas the smallest cross-set distance is 9001/1000. Every cross-count is zero. Therefore:\par
- Printed Eqs. (11)-(12) give C-Prec = C-Rec = 1.\par
- The intended cover definitions give PC = RC = 0.\par
Open versus closed balls does not change this example. The same zero-count argument applies to separated compact supports with all within-support diameters smaller than their separation. The error is established without interpreting a numerical plot [E6].\par
Reversing both signs to “at least” restores the cited empirical definitions exactly. This repair does not fix Problem 1. The local Minor judgment rests on the demonstrated scope: this is an incorrect printed specification, while the actual predicate in the released implementation already uses the intended direction. No false derived theorem or additional experimental corruption was established from this sign error alone.\par
\subsection*{6. Other checks, counterevidence and remaining boundaries}
Checks that passed. The Gaussian mean-separation extremes in B.2 have TV distances 0.9973002, 0.9999779 and 0.9999367. All six scale-separation extremes in B.3 also exceed 0.99; the smallest is 0.9968327. These independent numerical checks support the stated separation settings. Distinct concentric sphere surfaces are disjoint. Translating each coordinate of unit cubes by t = 1 - 0.2\textasciicircum{}(1/d) gives overlap volume exactly 0.2. Common invertible rescaling and adding independent identical variables preserve population TV [E6]. These checks do not reproduce finite-sample metric curves.\par
Radius policy discrepancy. At n = 1000 the text specifies k-prime = 13, k = 5, whereas the release uses k = 5 and k-prime = 3k = 15. This is a verified bounded specification mismatch. Its effect on the published results is unresolved; it is not needed for the Major conclusion.\par
Hypercube explanation. Section 5.3’s decreasing-distance intuition needs qualification. For independent unit-cube samples U and V displaced by t in every coordinate, EU-V\textasciicircum{}2 = d/6 + d t\textasciicircum{}2, which grows asymptotically. The distance between centres, sqrt(d)t, decreases. The latter is a defensible interpretation of the conjectural explanation; this is retained as a clarification, not a finding that the experiment is invalid.\par
Torus setup. Uniform cross-sectional disk sampling followed by uniform rotation does not give uniform volume density on a solid torus: its density is proportional to 1/rho. Nevertheless, the described torus (major radius 1, minor radius 0.1) remains disjoint from the radius-0.8 ball. The disjointness premise survives; no changed pass/fail result was demonstrated.\par
Scope of the position. The inclusion criteria explicitly exclude curve-valued and prohibitively slow metrics (p. 3). The title should be read with that evaluated scope. The chosen thresholds and notions of acceptable fidelity/diversity are stated desiderata, not universal statistical laws. Disagreement with those choices alone is not recorded as a mathematical error.\par
