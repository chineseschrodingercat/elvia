\# 2. Definitions and review assumptions\par
Let h be a fixed feature representation, P the ID feature distribution, Q the OOD feature distribution, and s(h) an OOD score, with larger values indicating OOD. For independent H\_P\textasciitilde{}P and H\_Q\textasciitilde{}Q, AUROC(s)=Pr[s(H\_Q)>s(H\_P)]+0.5 Pr[s(H\_Q)=s(H\_P)]. This is a pairwise ranking measure, not directly a fraction of individually unclassifiable images.\par
A binary linear classifier followed by a two-class softmax produces a score monotone in one affine function of h. It is a restricted member of the set of all feature-based scores. Training it on ID and OOD data gives it privileged labels, but does not remove its function-class restriction. The counterexample below permits infinite training data and exact optimization; it is not an optimization-failure complaint.\par
The Bayesian check uses the paper’s general stochastic-parameter formulation and a proper prior. The code findings concern the preserved public snapshot and documented commands; the code that actually generated published figures has not been established. Author code was not executed.\par
\# 3. Problem 1: a linear oracle does not establish irreducible feature error\par
Source claim and location. Section 4.1, p. 4, first describes an oracle as a binary linear classifier trained to distinguish ID and OOD features, then treats 1 minus its AUROC as irreducible error that no feature-based method can reduce. Figure 2, p. 5, uses that interpretation in its error decomposition. Section 5.6, p. 9, uses the same argument for a greater-than-5\% irreducible residual in the large DINOv2 representation. The released implementation explicitly constructs torch.nn.Linear(feature\_dim,2), ood\_score.py line 92 [S1-S3, E1-E3].\par
Suspect step. Let A\_all be the supremum of AUROC over all permitted feature-based scores, and A\_lin the best affine-score AUROC. Set inclusion gives the inequality below. An observed finite-trained oracle is no better a universal ceiling. The direction needed for the paper’s universal residual floor is not justified.\par
\[A_{\mathrm{all}}\ge A_{\mathrm{lin}},\qquad 1-A_{\mathrm{all}}\le 1-A_{\mathrm{lin}}.\] Complete counterexample. Set h(x)=x in one dimension. ID features take -1 and +1 with equal probability; OOD features take -2 and +2 with equal probability. The two ID classes are their signs, so a supervised linear classifier using this same representation classifies the ID labels perfectly. All four support points are distinct; no overlap or feature ambiguity is present. No assumption in the oracle argument requires continuous features or excludes these distributions.\par
For s(h)=w h+b with w>0, the OOD point +2 beats both ID points and -2 beats neither: two wins among four equally likely pairs, so AUROC=1/2. For w<0 the ordering reverses and again gives two wins. For w=0 every pair ties and AUROC=1/2. The two-class linear-softmax oracle has the same ordering. Yet s(h)=|h| or h\textasciicircum{}2 ranks both OOD points above both ID points, giving AUROC=1. This proves the claim for every affine score, rather than only for the finite coefficients checked by the independent script.\par
Quantity | Linear oracle | Nonlinear score using identical features\par
ID scores (example) | -1, +1 | 1, 1 using h\textasciicircum{}2\par
OOD scores (example) | -2, +2 | 4, 4 using h\textasciicircum{}2\par
AUROC | 1/2 for every affine score | 1\par
Residual 1-AUROC | 1/2 | 0\par
Alternative reading and counterevidence. The word ’proxy’ would support use of the oracle as an empirical comparator. It cannot support the subsequent assertion that no feature-based detector can do better. Exact equality of ID and OOD feature laws would indeed imply indistinguishability; the counterexample does not dispute that statement. It shows that failure of a linear discriminator does not establish such equality. Nor does it establish zero Bayes error for the actual ImageNet-derived feature distributions.\par
Supported impact and judgment. Major, limited to a substantial invalid inference underlying the central quantitative irreducible-error decomposition and universal floor. The reported comparisons among the named baselines remain empirical observations. The general warning that ID classification objectives need not guarantee OOD detection is not refuted.\par
Precise repair. Rename the quantity a linear-oracle residual and remove its interpretation as a universal irreducible component. The gap to the best tested score can still be reported descriptively. Richer held-out probes can test whether additional feature information is usable, but even a failed nonlinear probe is not by itself a proof of a Bayes upper bound. Establishing the actual irreducible error requires justified distributional assumptions or a valid bound. The revised interpretation is logically verified; the real-data residual cannot be repaired numerically without fresh analysis.\par
\# 4. Problem 2: unrestricted posterior collapse need not occur\par
Source claim and location. Section 5.3, p. 7, states that in the infinite-ID-data limit the posterior over model parameters collapses, and uses this to argue that epistemic uncertainty cannot retain an OOD signal. Section 6, p. 9, extends the decreasing-usefulness interpretation. This statement needs identification conditions on parameters that affect the OOD inputs. It is not a consequence of increasing ID sample size alone [S1, E1].\par
Assumption-satisfying example. Consider a two-class logistic network p(Y=1|x,theta)=sigmoid(theta1*x1+theta2*x2), with independent proper priors theta\_j in \{-log 3,+log 3\}, each equally likely. ID inputs are (1,0) and (-1,0), with labels generated by the specified model. The likelihood of any ID dataset is independent of theta2, so its posterior remains exactly its prior at every sample size, even if theta1 is learned perfectly. At the OOD input x=(0,1), the two possible predictive probabilities remain 1/4 and 3/4.\par
\[p(Y=1\mid x=(0,1),D)=\frac12,\qquad I(Y;\theta\mid x=(0,1),D)=1-h_2(1/4)=0.1887218755\ \mathrm{bits}.\] Here h2 is binary entropy in bits. The positive mutual information persists for every finite n and in the infinite-data limit because the ID likelihood contains no theta2 term. The independent checker evaluates the exact posterior symmetry and entropy, and the reasoning establishes the all-n statement.\par
Continuous proper-prior check. The same failure occurs with independent theta1 and theta2 uniformly distributed on [-log 3, log 3], so it does not rely on a discrete interpretation of the parameter integral. ID inputs (1,0) and (-1,0), each with positive probability, have model-generated labels. For every ID dataset, the likelihood contains only theta1; posterior(theta2|D) therefore equals its proper uniform prior exactly. At x=(0,1), symmetry gives predictive probability 1/2, while epistemic mutual information is 1 minus the prior expectation of h2(sigmoid(theta2)). Half the prior mass has |theta2| at least log(3)/2, providing the positive bound below.\par
\[I(Y;\theta\mid (0,1),D)\geq \frac{1-h_2(\sqrt{3}/(1+\sqrt{3}))}{2}>0,\] The bound is approximately 0.0262143336 bits and is independent of ID sample size. Strict positivity is analytic: binary entropy is strictly less than one away from probability 1/2. This establishes failure of unrestricted collapse, not any real-data AUROC or guaranteed detection success. The controller proof and independent arithmetic are retained in verification/0032/revisions/severity\_calibration\_controller\_001/evidence/.\par
Alternative interpretation and impact. For an identifiable finite-parameter model with posterior consistency and continuous predictions at the query point, posterior concentration can make predictive epistemic uncertainty vanish. That restricted rationale is defensible. It does not yield a general monotonic AUROC claim, and it does not apply when ID observations leave OOD-relevant directions unidentified. The displayed finite last-layer Laplace experiment is not refuted by this example.\par
Judgment: Major for the invalid unrestricted derivation. Section 5.3 uses posterior collapse to explain a fundamental mismatch with OOD detection; Section 6 carries that argument into its data-size deterioration claim and guidance on Bayesian/ensemble methods when ID data are abundant. This is a direct dependency of a core technical argument, not an isolated observation. Survival of the finite Laplace scores or the broad position does not downgrade this separate error. Repair: state identification and posterior-concentration conditions for every OOD-relevant parameter direction, retain the finite experiment within its actual scope, and withdraw the unconditional data-size inference. A conditional concentration statement alone also does not prove a universal monotone AUROC trend. No universally reliable epistemic OOD detector is claimed.\par
\# 5. Problem 3: released CLI and oracle routing are inconsistent\par
Source claim and location. Appendix B, p. 25, links the public reproduction repository. Its README provides python extract\_features.py and python ood\_score.py commands. Static inspection of the preserved commit identifies multiple linked blockers in that documented workflow [S3, E3].\par
Location | Observed source | Static consequence\par
ood\_score.py:204 | if \_\_name\_\_ == ’main’: | Normal direct invocation sets \_\_name\_\_ to ’\_\_main\_\_’; the parser/evaluation block is not entered, assuming imports succeed.\par
ood\_score.py:205-206,232,248 | linear\_oracle belongs to both logit\_methods and feature\_methods; if/elif dispatch checks logits first | After correcting the guard, linear\_oracle is captured by the logit branch, which has no corresponding oracle call.\par

extract\_features.py:266; get\_dataset.py:95 | get\_dataset(dataset\_name) omits required dataset\_dir | The documented extraction call does not pass the directory required by the preserved helper signature.\par
Complete check. Source was parsed with Python’s AST machinery without importing or executing author modules. The guard is a comparison of distinct string values under standard direct invocation. Dispatch membership and if/elif control flow establish the unreachable oracle branch. The call’s positional arguments were matched to its declared signature; the dataset helper likewise has a required directory parameter. The complete files and exact lines are retained, so these checks do not depend on a summarized code fragment.\par
Counterevidence and scope. Functions may have been invoked manually from unshared notebooks or a different historical tree. The defects establish a problem in the released documented workflow; they do not establish which code generated the paper’s numerical results. No runtime failure is falsely reported as observed: this was static inspection only.\par
Judgment: Minor for released reproducibility. A local guard correction to ’\_\_main\_\_’ repairs that control-flow condition, and passing the parsed dataset directory repairs that missing positional argument. Full oracle repair also requires unambiguous dispatch and a separate OOD training-feature input distinct from held-out evaluation data. These are supported repair requirements, not a tested end-to-end patch. No author files were modified and no full repair has been validated.\par

\# 7. Checks that passed and dependencies of the conclusions\par
Table A.1, p. 18: independent arithmetic over all 42 printed rows gives mean FPR@95 values of 66.5214\% (MSP), 61.5476\% (max logit), 62.6095\% (entropy) and 61.9024\% (energy). The rounded MSP mean of 66.5\% and the statement that each average exceeds 60\% are supported. This recomputes equal-setting-weighted printed-number means, not thresholds or predictions.\par
Appendix A.6 Gaussian toy: for ID N(0,1), OOD N(2,1), and density model N(mu,1), the reviewer derivation gives AUROC=a*b+(1-a)*(1-b), with a=Phi(sqrt(2)) and b=Phi(sqrt(2)*(1-mu)). It gives 0.8550723132 at mu=0 and approaches 0.9213503965 as mu tends to negative infinity, while KL from the ID distribution grows as mu\textasciicircum{}2/2. The limiting tradeoff described in the paper is consistent; the ’optimum at negative infinity’ is a supremum rather than a finite fitted mean.\par
The oracle PCA uses ID and OOD features by explicit design and searches a stated component-count set. It is a disclosed hindsight comparator, not hidden leakage. Its performance likewise does not certify a globally optimal feature detector. Appendix B.1 reports three-seed averages for the outlier-exposure comparison; no missing-seed allegation is made. The observed harm in selected settings can support a ’can hurt’ claim.\par
Scaling comparisons mix architecture, objective and pretraining data. They support descriptive comparisons among tested models, rather than an isolated causal scaling law. Appendix A.5 discusses pretraining exposure to related data. These limits do not negate the observed scores; the unsupported universal irreducibility interpretation is already covered by Problem 1.\par
Problem 1 is independent of Problems 2 and 3 and of the Figure 7 mismatch. Repairing the public script cannot turn a linear oracle into a Bayes performance bound. The paper’s distinction between label uncertainty and distribution membership remains useful within the inspected scope.\par
