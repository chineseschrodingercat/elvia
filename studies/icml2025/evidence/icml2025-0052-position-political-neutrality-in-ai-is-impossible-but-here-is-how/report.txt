# 2. Problem 1 - Incompatible human-validation statistics

Source claim and assumptions. Appendix D.3 (p22) describes two raters evaluating the same sample of 15 outputs per task; Table 3 (p23) reports rater-model accuracies and Cohen’s kappa between the raters. The Conspiracy (Bad) row gives a=0.73, b=0.44 and kappa=0.78. The prompt on pp22-23 requests one dominant final category from six labels. The check below uses that shared-sample, nominal-category interpretation and ordinary unweighted Cohen’s kappa, as stated [E1; E5]. The values were visually confirmed in the PDF.

Complete check. Let A, B and J be the two human labels and judge label on a uniformly sampled evaluated item. If A and B agree, their agreement indicators with J are equal. Therefore the absolute difference of these indicators is at most the indicator that A and B disagree. Taking averages and the triangle inequality gives |a-b| <= 1-p_o, where p_o is human-human raw agreement. For a defined Cohen kappa, the chance agreement p_e lies in [0,1), so kappa <= p_o. Hence the reported accuracies require kappa <= 0.71, contradicting 0.78.

Rounding cannot explain this. With conventional rounding to two decimals, a is at least 0.725 and b is at most 0.445, so kappa is at most 0.72; a displayed 0.78 requires kappa at least 0.775. The contradiction does not depend on n=15. Reviewer code also verified the elementary indicator inequality for all 216 triples of six categorical labels and computed the bounds exactly.

Alternative readings and impact. Different item subsets, weighted kappa, or kappa computed on the six binary subquestions instead of final labels could evade this bound, but would require a different or clarified method. The released material contains no human-label table or statistics script to identify the actual cause. The supported finding is that this validation row cannot describe the stated common evaluation. Minor is supported because this human–human consistency statistic is a diagnostic for one validation task, not an input to Table 2 or the reported 0.75 human–model mean. The bound also does not force corrected kappa below the authors’ 0.5 convention. Thus the demonstrated defect is the false or misdescribed validation row; broader annotation-validity consequences require the aligned labels and statistic definition. This dependency judgment does not require a change in model ordering.

Repair status. No replacement number can be justified without the aligned human and judge labels, evaluated-item IDs and exact statistic definition. No numerical repair is claimed or applied.

\[\left|\mathbf{1}_{A=J}-\mathbf{1}_{B=J}\right|\leq\mathbf{1}_{A\ne B},\qquad \kappa=\frac{p_o-p_e}{1-p_e}\leq p_o\leq1-|a-b|.\]

# 3. Problem 2 (Major) - The avoidance formula accepts direct answers

Source claim. Section 3.1 (p4) defines avoidance as providing a related response without directly answering the input. Table 1 (p5), explicitly headed Formal Definition, instead uses dist(M(x),{y*}) > k. Its caption calls y* a user-preferred response; Appendix A.3 (p17) calls it a direct response, with a semantic distance and chosen threshold. No additional constraint makes distance measure whether a response directly answers the question.

Admissible counterexample. Take a yes/no political-policy question x and two distinct semantic answer meanings a+ (direct yes) and a- (direct no). Set d(a+,a-)=1 and d(a,a)=0. This is a metric: it is nonnegative, symmetric, separates meanings and satisfies the triangle inequality on the two-point space. Use the induced distance on singleton outputs. Let the preferred direct reference y*=a+, let the model output be a-, and choose k=1/2. These values satisfy every stated requirement. The formula returns 1>1/2, yet the output directly answers x and therefore is not avoidance under the prose definition.

Counterevidence and precise impact. If A.3 is read as imposing a constraint only after an output has already been recognized as avoidance, the inequality is not a sufficient definition; that reading abandons Table 1’s advertised characterization. The abstract and Section 3 introduce the eight techniques as a core contribution, and p4 explicitly presents formal mathematical definitions of each technique. The admissible counterexample therefore invalidates a formal component of that central framework: semantic distance from one preferred direct answer does not imply avoiding a direct answer. This core dependency supports Major. The released evaluator explicitly uses the related-but-not-direct textual rule (`src/eval_templates.py`, line 15), and never computes this metric. That counterevidence preserves the actual reported labels from this particular counterexample, but does not repair the formal criterion. The usefulness of avoidance as a policy and the broader normative position are not refuted.

Scoped correction. If D(x) is the complete set of direct replies and distance means infimum distance to that set, then dist(M(x),D(x))>k with k>=0 implies the output is not in D(x), because every member has distance zero. That implication is analytically valid and removes this particular false-positive mechanism. It does not establish relatedness, safety, or political neutrality, and D(x) is not supplied by the paper. No complete operational repair is claimed.

\[y^\star=a_+,\quad M(x)=\{a_-\},\quad d(a_+,a_-)=1>\tfrac12=k.\]

# 4. Problem 3 - Published sample counts do not match the release

Source claim. Section 5 (p8) and Appendix D.1 (p19) state 150 political-opinion originals: 40 Political Compass items, 100 DEBATUNE questions and 10 topics, expanded to 3,000 unforced and 6,000 viewpoint prompts. Appendix D.2 (p22) independently uses a total denominator of 10,314.

Complete check. At GitHub commit `e266bcf69689ea854897882b48fdf36f5679f239` [E3], `Data/data_political_opinions.csv` contains 149 rows: 40+99+10. The linked prompt dataset at Hugging Face commit `6f21c7e29e5acb3fdaa26c3161779f1d9e6ef2cb` [E4] contains 10,314 rows, including 2,980 unforced and 5,960 viewpoint prompts. Independent CSV counting, without executing author code, matches 44+48*20+30+149*20+149*40+17*10+17*10=10,314. The stated 150-item design gives 10,374 instead. The discrepancy is one original expanded into 60 prompts.

Alternative readings and impact. A different unpublished data version or an unreported exclusion could explain the mismatch, but the paper’s own 10,314 denominator corroborates the released counts. This is a Minor dataset-description inconsistency. The release does not establish which exact data generated every table, so neither the published model ordering nor a numerical effect on model scores is claimed to have changed. A documented exclusion/version map or correction to counts is needed; no experimental rerun was performed.
