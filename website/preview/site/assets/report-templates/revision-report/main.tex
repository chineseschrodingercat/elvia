{\Large\bfseries\color{elvia} ELVIA: Review and revision report}\par
{\small Editable scientific template, version 2026-10-23. This is a template,
not a completed review or an endorsement.}
\guidance{Use this template for a paper already in ELVIA. Address the exact published
report/version you reserved. You may support, qualify or challenge earlier findings
and add new problems. A focused response to one finding is sufficient. Replace
prompts, keep source identifiers, and delete optional sections you do not use.
Compile with pdfLaTeX or XeLaTeX, or upload one complete UTF-8 .tex file.
Use a self-contained document without external images, input files or bibliography
files; submit a self-contained PDF if those resources are essential.}

\textbf{Submission files}
\begin{itemize}
\item This report: one PDF or one complete .tex file.
\item The original article and main supplement are already linked. Do not upload
them again in this revision route.
\item Optional verification code: one ZIP or 1--10 source-code/support files,
at most 5 MB total, including unpacked ZIP contents. A README with versions,
commands and expected outputs is helpful; no prescribed folders are required.
\end{itemize}
Do not package the report into a ZIP. Use the report slot and optional code slot.

\section{Response to existing Problem \prompt{n}: \prompt{title}}
\guidance{Repeat for each existing problem addressed. Keep the original number
and title even when your conclusion differs.}
\entry{Earlier finding}{Faithful short quotation or paraphrase and its exact
location in the prior report.}
\entry{Paper location}{Original PDF page/section/equation/figure, or code file/lines
and commit relevant to this finding.}
\entry{Your position}{Agree, partly agree, disagree or unresolved. Explain precisely
which premise, derivation, interpretation or impact statement you are assessing.}
\entry{Assumptions}{Definitions, scope, units, parameter range and stated versus
inferred conditions.}
\entry{Independent check}{Inspectable reasoning, derivation, counterexample,
calculation, data/control analysis or code check. Identify actual runs and outputs;
distinguish proof, finite checks, observations and conjecture.}
\entry{Result and counterevidence}{What the check establishes, alternative readings,
contrary evidence and whether the earlier concern survives.}
\entry{Requested revision}{Exact change to the earlier statement, reasoning,
severity or status, and a replacement statement if useful.}
\entry{Severity/outcome after this check}{Minor; Major; Needs evidence;
No issue found within scope. Justify the effect on the specific scientific claim.}
\entry{Limits}{Unresolved steps, failed attempts and what the check does not establish.}
\guidance{Major requires demonstrated impact on a central claim; Minor is a bounded
local issue. Needs evidence leaves validity or impact unresolved. No issue found
within scope applies only to the claim and conditions actually checked.}
