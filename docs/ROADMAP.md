# Project direction

ELVIA makes scientific arguments easier to inspect, discuss and improve. The
current service combines an Atlas of 300 NeurIPS 2025 papers with accounts,
contribution submissions, review assignments and amendments.

## Priorities

1. **Review and publication.** Compare contributions with the current note,
   approve individual changes, preview the result and publish a new version
   through the same template.
2. **Independent participation.** Build sustained review around well-defined
   claims, relevant expertise and explicit conflicts of interest.
3. **Discovery and reuse.** Improve search, citations, readable evidence packages
   and navigation across related arguments.
4. **Coverage.** Add reviewed collections when their sources, selection rules and
   available expertise support meaningful analysis.
5. **Operations.** Improve backup and availability as usage grows.

[GitHub Issues](https://github.com/chineseschrodingercat/elvia/issues) track
concrete work and acceptance criteria. Priorities are not delivery dates.
