# Readable evidence without reducing public context

Date: 2026-10-23

The maintainer authorized a follow-up to the P0 public-discovery work: show the
key finding and limitations directly, while making long supporting arguments
expandable. [Issue #14](https://github.com/chineseschrodingercat/elvia/issues/14)
owns implementation, verification and deployment status.

The finding's complete recorded result, case limitations and review status stay
visible. Source claims, assumptions, detailed checks and any proposed repair use
native `details`/`summary` disclosure. The full evidence remains in the initial
HTML response; expanding it does not fetch or generate scientific content.
No-issue and scope-clarification notes follow the same evidence-access pattern.

Copy for AI and citation exports are independent of the visible disclosure state
and retain their exact content, source identity and scope. The authoritative JSON
records, scientific wording, attachments and adjudication status do not change.

Verification must cover keyboard/mobile reading, fragment navigation, complete
printed evidence, source-HTML preservation and unchanged export packets. This
preserves content availability for crawlers; it cannot guarantee how an external
search engine or AI system selects, indexes or cites that content.
