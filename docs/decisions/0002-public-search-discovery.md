# Public search discovery

Date: 2026-10-22

Issue: https://github.com/chineseschrodingercat/elvia/issues/2

The maintainer authorizes public indexing, independent case URLs, a sitemap,
Google Search Console submission, source synchronization and deployment.

Generate readable HTML from the same validated snapshots and revision-bound
catalogs as the interactive Atlas. Keep scientific record and evidence bytes
unchanged. Preserve existing shared links, current download contents and offline
build defaults. Index the public reading and information pages while retaining
exclusions for accounts, recovery, APIs and errors.

Use a public homepage meta tag to verify the existing HTTPS website in the
maintainer's Google account. This needs no DNS change, additional hosting or
tracking script. Retain the tag after verification. Record submission separately
from subsequent indexing and ranking, which Google controls.

Provide public participation and platform guides to answer researchers' actual
questions. Search terms are hypotheses until supported by measured query data.
See [search discovery](../search-discovery.md) for the page and intent map.
