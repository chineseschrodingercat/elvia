# First-visit discovery and contextual contribution entry

Date: 2026-10-22. Tracking: [Issue #6](https://github.com/chineseschrodingercat/elvia/issues/6).

An expanded guest walkthrough exposed a path omitted by the previous 9/10
heuristic assessment. The participation guide's primary action opened a guest
workspace that sent the visitor home without the selected paper/finding. The
separate direct registration link worked. The expanded initial route scored
6/10: one major continuation failure, delayed search, and interpretation burden.
These scores describe an AI-assisted walkthrough, not observed human conversion.

## Decisions

- A guest's primary finding action opens registration with a validated local
  workspace return route. Signed-in members continue to the workspace. If session
  lookup fails, usable contextual registration and sign-in links remain visible.
- Direct guest workspace visits provide the same contextual account actions and
  a small report starter. Assignment queues and role administration do not lead
  this first-visit view. Server permissions and eligibility rules are unchanged.
- The homepage presents search and three real questions from the current
  collection: DFloat11 initialization, conformal coverage, and 4D-VLA depth
  preprocessing. Questions preserve the source scope and preliminary status;
  they are not new scientific conclusions or selected examples of confirmed errors.
- Atlas search and records precede extended assessment definitions and collection
  counts. A visible preliminary-review notice remains beside the introduction.
- A plain-text report template and a clearly fictional normalization clarification
  explain the smallest supported report. A standard ZIP containing the edited
  report needs no special folder structure or manifest. Extra evidence is needed
  where the contributor's actual check requires it. Templates do not supply human
  independence, conflicts, AI-use declarations or scientific judgments.
- Registration explains saved drafts, submission review and optional named credit
  before secondary role rules and daily limits. The example opens separately from
  an active form; template download links do not replace entered form values.

## Acceptance scope

Verify both primary and alternate guest paths, signed-in continuation, session
failure fallback, homepage search/reset, real featured-link identities, template
download/ZIP acceptance, desktop and narrow layouts, and preserved registration
context. Use isolated fixtures for account or draft mutations. Required local and
five CI checks precede compatible deployment; inspect the actual merged head and
public pages. Preserve scientific snapshots, reader PDFs and all operational state.

Record measured layout and actual checks in STATUS and the Issue. Do not infer
registration uplift, search ranking gains or scientific correctness from this
engineering pass.
