# Case-note reading layout

Date: 1 November 2026 (America/Chicago)

Issue: https://github.com/chineseschrodingercat/elvia/issues/29

The maintainer requested a less repetitive reading layout across the full Atlas.
This supersedes the reading-layout portion of decision 0010; it does not change
scientific records, findings, review decisions or downloadable evidence.

## Overview and actions

Place the actual independent-review status beside the assessment badge. Keep
the live contribution-availability panel and its revision entry. Remove the
separate review-status/abstract panel, its contribution link and the contents
navigation.

Keep one whole-note pair of citation actions and one citation-formats/full-context
disclosure. Remove the direct Copy for AI button and all finding-level citation,
contribution and return-to-overview controls. Full context and source finding
identifiers remain available in the original data and exported packets.

Show Key findings before numbered problems. Use the existing concise
problem-specific briefs, or their titles when no brief exists, in the same
severity-sorted display order. No Issue Found and scope-clarification cases keep
bounded outcome summaries without acquiring artificial problems.

## Problem evidence

Each problem uses Problem statement, Sources, Proof or Verification, and Possible
revision. Preserve complete premises, method paragraphs, intermediate reasoning,
formula rendering and existing anchors. Method prose belongs with the argument
rather than the source locator.

Sources removes repeated importer field names and internal extraction offsets.
Merge only explicitly listed consecutive PDF pages; preserve gaps and the
distinction between article and supplementary sources. Retain actual theorem,
lemma, equation and section locators without inventing a correspondence between
parallel page and label lists.

Possible revision displays the report's existing problem-specific repair text.
When that field is empty, an explicit corrective proposal in the same problem's
retained analysis or result can supply the original paragraph, including its
scope. Negated fixes and unspecified future tasks are not proposals. An absent
proposal displays Not available. It never relabels a finding's result
as a repair or invents a new correction. Detailed finding and scope is removed
from the problem interface; the original results and qualifications remain in
the scientific records and full context. Non-problem evidence retains Review
scope.

## Acceptance

Cover both static pages and the dynamic Atlas, synthetic source-range and repair
regressions, a representative mathematics note, an older ML note and a narrow
layout. Retain the unchanged 1,214 scientific snapshots and existing download
bundles. Use the existing local checks, five final-head CI checks and compatible
deployment with a fresh verified backup and state-preservation comparison.
