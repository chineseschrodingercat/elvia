# Complete reader evidence and mathematical case notes

Date: 27 October 2026 (America/Chicago)

Issue: https://github.com/chineseschrodingercat/elvia/issues/23

The maintainer found that case notes named verification files that were absent
from the reader ZIP. Checking a package against a two-PDF manifest did not check
whether the scientific argument's cited evidence was available. This decision
supersedes the PDF-only download policy and the repeated case-wide evidence
section in the previous reading layout.

## Download coverage

Each published case must map its cited article, report and supporting evidence
to actual downloadable members. Retained text fragments, source screenshots,
scientific calculations, check scripts and result files are eligible evidence.
An explicit reviewed publication mapping selects the files, records their hashes
and gives readers portable names. Neither a directory scan nor an archive's mere
presence authorizes publishing unrelated files.

Validate the retained source identity, selected public bytes and final ZIP
membership. Where an evidence file contains internal operational metadata, keep
the scientific material in an explicitly identified public copy. Do not invent
missing sources, silently omit referenced evidence, execute author programs or
claim a check was repeated. Original inputs remain preserved.

Credentials, account data, conversations, provider settings, internal logs and
unrelated private tooling remain excluded. Third-party source terms and article
attribution continue to apply. The current report and exact original article
remain available alongside the supporting files.

## Reading layout

Use one concise whole-article Analysis abstract describing the issues and their
impact. For each actual problem, integrate conditions into a complete Problem
statement, preserve Source and Method, and give a complete Proof or Verification
argument followed by Detailed finding and scope. Mathematical, software and
other arguments must retain their intermediate reasoning. A proof-ending square
marks an established finding, rather than claiming an unresolved source claim
has been proved. Do not display Recorded correction or add replacement solutions.
Keep the scientific repair history in the authoritative records.

Order actual problems Major, Minor, then Needs Evidence, preserving source
identifiers and order within a grade. No Issue Found is not a problem and is
excluded from the sequence. Such articles retain ordinary bounded inspection
and scope prose. Avoid unnecessary bullet lists.

Assign visible Problem 1, Problem 2, and subsequent numbers after severity
sorting and filtering. Keep original finding identifiers, source numbers and
existing anchor/query mappings separate from display numbering. Citations and
AI context must identify the same source finding while using the visible number.

Supporting record & provenance uses short verbatim original-paper excerpts and
their PDF/theorem/page locators when they are readily extracted. Honest
mathematical ellipses may omit intervening text. Difficult mathematical or
damaged extraction uses the source locator alone. Never put a report's paraphrase
in quotation marks as an original claim. Apply this policy to all 700 articles.

Use mathematical notation where it makes the argument precise. Paths, byte counts, hashes and repeated status fields belong
in the downloadable file mapping rather than the argument's prose. Direct
readers to the report ZIP for supporting files.

Remove Case-wide scope and evidence and its links. Keep relevant qualifications
with the finding, truthful review status in the overview, and source identity and
revision information in Supporting record & provenance. Complete maintained
reports remain downloadable. These presentation changes neither adjudicate the
findings nor remove scientific limitations.

Scientific numbers, statistical quantities and formulas use mathematical
typography. Preserve existing correct LaTeX, source locators, identifiers, URLs
and code. Recover malformed formulas from the retained report rather than
guessing their operators or assumptions.

## Acceptance

Check all 700 cases against the evidence mapping and actual ZIP bytes, rather
than checking only an assumed file list. This is a local packaging check. The
maintainer explicitly excludes repetitive public ZIP download tests and
prioritizes rigorous statements and proofs. Use representative initial-HTML,
browser fallback, Copy for AI, mathematical-rendering, keyboard-disclosure and
narrow-layout checks; do not repeat exhaustive page/link checks. Use ICML 0268
as a regression example for both evidence coverage and
set/threshold/rank notation. Retain independent scientific review as pending.

Run the required local and isolated website checks, installed-wheel smoke and
the five checks at the final main head. Deploy with a fresh stopped-writer
backup, a separate restore-copy rehearsal and protected-state comparison, then
check canonical public pages and the exact shared mathematical renderer before
closing Issue #23. Preserve decimal exponents and source-attested operators;
successful LaTeX parsing alone does not establish a faithful expression.
